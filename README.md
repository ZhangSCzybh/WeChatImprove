# WeChatImprove

面向 iOS 微信的 Theos 插件，使用 Objective-C / Logos 接入微信原生界面，提供聊天分组、界面定制、消息增强、自动回复和配置备份等功能，可在插件设置中按需开启。

**源码版本：`2.9-6`** · **架构：`arm64` / `arm64e`** · **最低编译目标：iOS 15.0**

[功能概览](#功能概览) · [安装与入口](#安装与入口) · [使用说明](#使用说明) · [配置与备份](#配置与备份) · [源码编译](#源码编译) · [开发与验证](#开发与验证) · [常见问题](#常见问题)

## 安装与入口

需要能够向微信加载插件的 iOS 注入环境。近期适配参考为微信 `8.0.78`、`8.0.80`，广告净化等私有接口以 `8.0.80.34` 为核验依据；这不代表所有系统、微信版本及插件组合均已通过真机验证。安装包声明依赖 `mobilesubstrate >= 0.9.5000`。

当前源码版本为 **2.9-6 正式版**。用户已确认 beta03 在原设备滑动正常；正式版沿用该接入与手势保护，移除临时滑动检测入口和诊断记录，保留“文本占位 → 输入框滑动”的全部功能。可独立配置左滑、右滑对当前聊天输入内容执行的操作，模块默认关闭。继续包含 `2.9-5` 的聊天分组冷启动与顶部提示刷新修复、深色模式适配、底栏选中图标颜色、快捷面板新增入口及主页转场调整、语音转文字气泡适配、朋友圈位置图标更新和当前聊天分组动画调整。按现有注入环境选择：

| 环境／产物    | 下载                                                                           | 说明                                                      |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------------------------- |
| Rootless | [安装包](packages/2.9-6/com.wechat.improve_2.9-6_iphoneos-arm64.deb) | 安装至 `/var/jb/Library/MobileSubstrate/DynamicLibraries/` |
| Rootful  | [安装包](packages/2.9-6/com.wechat.improve_2.9-6_iphoneos-arm.deb) | 安装至 `/Library/MobileSubstrate/DynamicLibraries/`        |
| 重签用动态库   | [WeChatImprove.dylib](packages/2.9-6/WeChatImprove.dylib)              | 与 Rootful 包内动态库一致                                       |
| 校验与调试    | [SHA-256 清单](packages/2.9-6/SHA256SUMS) · [调试符号](packages/2.9-6/symbols.zip) | 产物详情见[发布说明](packages/2.9-6/README.md)     |

正式版已提供 Rootless、Rootful 与重签动态库，338 项核心主机回归、双架构编译和包内容核验均已通过。用户的原设备可用确认对应 beta03；正式版执行记录见随包说明。

两种安装包均包含 `arm64` / `arm64e`。包名中的 `iphoneos-arm64` / `iphoneos-arm` 是打包方案的架构标识，应按注入环境选择。Roothide 保留源码构建入口，尚无当前版本的运行验证结论。仓库未提供可直接安装的 IPA 或一键重签流程。

1. 使用设备上适配当前环境的包管理器或安装工具安装，并按工具提示重新加载注入环境。
2. 完全退出并重新打开微信，进入 **我 → 设置 → 再也不会**。
3. 按页面提示完成公众号关注验证和首次使用声明，再开启所需功能。

默认入口名称为“再也不会”。在 **入口设置** 中可修改名称，或改为显示在“我”页面、微信设置页及已有插件管理入口；后者需要宿主环境提供 `WCPluginsMgr`。

## 使用说明

以下路径均从插件设置首页进入。

### 首页顶部信息

顶部卡片从上到下依次显示账号区、随机文案和三张状态卡片。账号区保留头像，右侧第一行显示昵称和紧随其后的 SVIP 标识，为标识预留宽度以避免长昵称挤出；第二行以普通文字显示“微信号：”和微信号值，未取得微信号时沿用原有提示。SVIP 使用固定浅金色背景、黑色衬线文字和小圆角矩形，刷新和重新布局时保持一致；仅作展示，不改变授权状态或功能权限。文案位于账号区与状态卡片之间，状态卡片按单行／双行文案的实际展示高度向下排列，并保留区间留白；继续适配小屏、大字号和完整插件版本。

底部三张状态卡片从左到右为“已开启”、插件版本和微信版本。“已开启”按当前配置统计普通功能模块，每个模块最多计一次，密友保护不计入数量；返回首页或配置变化后刷新。微信版本读取当前安装的实际版本，不受插件内微信版本返回值设置影响。

随机文案在每次重新进入插件设置首页时发起一次新请求，停留期间切换 Tab、搜索、下拉或从详情返回不重复请求，[诗词接口](https://api.qemao.com/api/Verse/)与[随机一言接口](https://api.yujn.cn/api/sjyy.php?)按进入次数轮换。诗词仅保留正文并去除末尾标题和作者，随机一言读取纯文本并去除尾部署名。首个来源失败或返回当前缓存中的相同文案时，再尝试另一来源一次，每次进入最多请求两个来源；两个来源都失败时使用已缓存句子，无缓存时显示本地兜底。上游可能随机返回相同内容，不保证每次文案不同。请求不阻塞设置页面，也不改变头像长按 2 秒发现密友入口和连续五击后确认进入的流程。

### 聊天分组与外观

进入 **界面定制 → 聊天分组**，打开“启用聊天分组”后返回聊天列表。可创建自定义组、管理成员、排序和隐藏预设组；同一会话可以加入多个自定义组。删除分组仅移除配置，保留会话和聊天记录。

- **搜索**：默认使用分组栏右侧按钮进入微信原生搜索；关闭“显示分组栏搜索按钮”可恢复原生搜索区域。
- **横滑**：开启“分组切换手势”后，从会话列表左侧 `85%` 区域起手切组，从最右侧 `15%` 起手左滑打开原生会话菜单。搜索时暂停切组。
- **折叠的聊天**：跟随当前分组与密友规则筛选；折叠状态仍由微信全局管理。
- **气泡与合并**：在“气泡样式”中配置圆角和浅深色收发配色。“连续消息合并”可独立开启，支持保留首条或末条头像，以及正常／紧密间距；昵称、头像和未适配的附加内容仍可能保留必要空间。
- **列表与底栏**：“列表圆角”调整卡片、边距和背景；“底栏样式”配置悬浮布局、图标、文字与动画。系统开启“减弱动态效果”时停用相关动画。

列表圆角在通讯录、发现和“我”页面同步适配浅色、深色外观，包括卡片外围、分组标题和页脚；切换外观后刷新当前页面，保留各自配置的卡片颜色。底栏样式中的“选中图标颜色”可自定义，也可恢复微信原生默认；默认颜色跟随微信当前外观。上传的普通或选中图标优先保留图片原色，未上传选中图片时沿用普通上传图片，因此选中色仅用于实际使用原生图标的项目。

### 消息与语音

**界面定制 → 文本占位 → 输入框滑动**可为当前聊天输入框分别配置左滑和右滑操作：禁用、清空输入框内容、复制输入框内容、剪切输入框内容、粘贴、发送。模块总开关独立于占位文本、圆角和边框，默认关闭，两侧动作默认禁用；仅在聊天输入框内单指横滑时生效。

清空、复制和剪切针对整段输入内容；粘贴插入当前光标处或替换选区；发送等同点击当前聊天的微信原生发送按钮。输入法组合输入和听写期间跳过操作，避免改动尚未提交的内容。三项配置支持备份、恢复与重置，并计入首页已有文本占位模块的开启数量，每个模块最多计数一次。用户已确认 beta03 的实际滑动正常；正式版保留该实现中的光标、选词与返回手势保护，其他设备和插件组合以各自实际使用情况为准。

`2.9-6` 沿用 beta03 已由用户确认可用的占位样式输入视图接入，保留当前聊天输入框关联及输入框内部、聊天视图以内祖先手势的范围仲裁，排除屏幕边缘和导航返回手势，并在松手后执行一次动作。正式版移除“滑动检测”、检测弹窗和复制检测结果入口，以及对应的临时诊断代码；启用后设置区仅保留总开关、左滑动作和右滑动作三行。beta01、beta02、beta03 安装包与发布记录继续保留供追溯。

在 **功能增强 → 消息手势** 中，可分别为己方／对方消息的左右滑选择引用、删除、转发、收藏、撤回、复读或禁用，具体动作受微信原生能力与消息类型限制。

**语音转发**中的聊天转发、收藏语音转发和语音进度拖动分别控制。收藏转发仅支持独立的语音收藏：打开收藏语音后，通过右上角菜单“发送给朋友”选择目标。进度拖动开启后，在正在播放的普通聊天语音气泡上横滑预览时间，松手后定位并继续播放；实际定位精度由微信原生语音格式决定。

在 **表情功能** 中开启“图片添加到表情”后，可长按普通聊天图片使用微信原生添加流程。**小丑功能**需同时开启总开关和相应子项，再长按对应内容修改显示；修改仅保存在当前聊天页面的内存中，离开后恢复，不改变原消息、图片文件或真实转账状态。

### 自动回复、AI 与定时任务

这些入口位于 **功能增强**，按微信账号保存相应配置，启用前需配置生效会话或目标。

| 入口   | 使用要点                                                                                 |
| ---- | ------------------------------------------------------------------------------------ |
| 自动功能 | 四个模块默认关闭，空名单不执行。支持拍我回拍及撤回、拍我回复、群聊真实 @ 回复、关键词回复；延迟可设为 `0–300` 秒，`0` 秒表示事件入站且条件通过后立即尝试 |
| 人工智能 | 填写 HTTPS API 地址、API Key 和模型，测试连接后开启总开关与会话开关。支持多个命名预设；群聊默认被单独 @ 时回复，可为当前群开启“免 @ 回复”   |
| 定时任务 | 每个任务向一个目标发送文字；支持单次、按分钟／小时、每天、每周，以及可跨午夜的时间段内执行。单项启用仍需总开关开启                            |
| 群聊功能 | 选择群聊后配置欢迎文案、退群提示和可选的本群通知；自动保存通讯录只处理有新入群证据的群。批量退群需原生选群并确认，已提交的退出无法撤销                  |

真实 @ 自动回复优先于关键词回复，固定回复认领后同一事件不再交给 AI。关键词只匹配本条正文，不匹配引用内容；自动发出的消息不会再次触发本插件关键词规则。

“拍动后台兜底补拉”默认关闭，AI 的“后台兜底补拉”默认开启，分别控制主动补拉。自动处理依赖微信实际收到事件并获得执行机会；系统挂起、进程退出或设备关机时，不能保证实时回复或定时准点，补拉间隔也不等于消息送达时限。

AI 启用后，符合规则的消息、有限上下文及可选图片会发送到所配置的服务。API Key 和原始图片不随配置备份导出；更换设备后需重新检查凭据与开关。

### 快捷面板

进入插件首页 **增强 Tab → 快捷面板**，入口紧随“自动功能”。总开关默认关闭，关闭时仍可配置和预览；默认勾选“微信主页底栏上滑”，可改选“聊天输入框上滑”，也可同时勾选，两项至少保留一项。从选定区域向上滑动打开面板，点遮罩、点顶部把手或从把手向下拖动关闭。

面板顶部显示当前微信账号的头像、昵称、微信号和本地时间日期，使用系统圆润字体设计；时间保留等宽数字，中文按系统可用字体回退。四列入口按已添加列表顺序排列；点已添加入口可移除，点可添加入口可追加，右上角“排序”可拖动调整。全部 21 个可选入口为：扫一扫、钱包、朋友圈、我的二维码、收藏、插件主页、个人资料、发起群聊、添加朋友、表情商店、面板设置、付款码、视频号、文件传输助手、聊天背景、收款码、我的朋友圈、新建笔记、切换账号、深色模式切换、全局搜索。默认添加原有 8 项，其余项目可按需添加；已有配置不会自动插入新入口或调整排序。允许移除全部入口，空面板保留设置提示。

设置页中的预览与实际面板共用内容视图，预览点击不会打开微信页面。实际入口经中央路由检查当前页面、账号和原生接口后执行；收藏沿用已有生物认证策略，插件主页与面板设置沿用授权与密友入口保护。微信版本缺少对应能力时显示提示。发起群聊需要同一导航栈中的微信首页原生控制器；无法取得时提示从微信首页或其聊天页面使用。账号切换、页面退出或场景失活会取消相关面板与失效跳转。

预览下方的背景区域可选择“默认／纯色／图片”，使用系统取色器设置颜色或从照片选择器导入单张图片；图片会缩放后保存在插件资源目录。透明度为 0% 时背景不透明，100% 时完全透明，只作用于背景，头像、文字与入口保持正常显示；文字按背景颜色和透明度选择深浅。取消选图保留原设置，“恢复默认背景”仅重置背景样式、颜色、透明度及已导入背景图。预览与实际面板共用背景渲染，面板内部不再显示“快捷面板”标题。

背景分组下方的“面板配色”提供字体颜色、图标颜色和恢复默认配色。字体默认随背景选择深浅，自定义后应用于顶部信息、入口名称及空面板提示，辅助文字保留同色的透明度层级；图标默认使用“界面调色”的原色，自定义后固定为所选 RGB。默认模式下更换界面调色会同步更新图标，自定义模式不受其影响。两项均可分别恢复默认，“恢复默认配色”只清除这两项覆盖，背景、透明度和入口顺序保留。

“聊天背景”打开微信全局的“设置 → 聊天 → 聊天背景”页面。文件传输助手通过当前账号联系人和微信首页原生会话入口打开，并检查最终聊天目标。

“收款码”通过微信原生“面对面收款”入口打开二维码收款页，与“付款码”分别添加和排序；如微信要求开通或验证，按原生页面提示继续。该项可在“可添加入口”中添加，并随入口配置备份。原生页面显示仍待真机验收。

“我的朋友圈”调用微信原生个人朋友圈入口，目标为当前账号的个人朋友圈／相册页；原有“朋友圈”继续打开好友动态列表。两项可分别添加、移除和排序，并随入口配置备份。个人入口优先复用“我”页面的原生动作，必要时通过已有微信主页入口打开；实际页面显示仍待真机验收。

“新建笔记”调用当前窗口的微信原生写笔记入口，由微信初始化编辑器；开启收藏生物识别保护时，先使用相同的面容 ID／触控 ID 策略验证，验证完成后重新核对账号和当前页面。

“切换账号”调用微信设置中同名按钮实际绑定的原生入口。以用户提供的 8.0.80 IPA 和同版本头文件核对：该按钮绑定 `NewSettingViewController.showLoginInfo`，首次使用提示由微信展示并续接后续流程。快捷入口会复用当前可见的原生设置页，或建立一个原生设置页；等待其进入当前窗口且转场结束后，只提交一次原生动作，并检查账号选择页或该设置页持有的原生首次提示是否出现。仅打开设置页、仅调用方法都不作为已打开后续界面的证据；无响应会超时提示，返回、切换页面、后台或账号变化会停止观察。后续提示、账号选择及认证由微信处理。不兼容时提示使用微信原生设置入口；实际页面展示、返回和单账号行为仍待真机验收。两项新入口均支持独立添加、移除、排序及备份。

快捷面板九项配置按全局设置保存，支持备份、恢复与重置，背景图片随资源备份迁移，不在备份中保存头像或账号身份。缺失的背景图片在界面中回退到默认背景。手势与跳转的主机回归和编译检查不能替代实际设备验收。

“深色模式切换”读取微信当前深浅外观，通过当前账号的原生深色模式管理服务切换到相反外观。点击后微信进入明确的浅色或深色模式；如需恢复跟随系统，使用微信“设置 → 通用 → 深色模式”的原生开关。“全局搜索”复用微信首页搜索按钮的原生流程；从其他主页 Tab 使用时交接到微信首页，再打开搜索。两项均可独立添加、移除、排序及备份，具体原生接口核验与真机验收项见[适配说明](docs/features/appearance-and-quick-panel.md)。

### 密友与隐私

**账号与安全 → 捉迷藏呀**首次默认隐藏。在插件设置首页长按顶部头像 **2 秒**可发现入口，再设置独立密码并选择密友／密群。支持临时解锁、首页长按解锁、密码搜索解锁，以及可选的生物识别和摇动锁定；进入后台、切换账号或重启后重新隐藏。

隐藏作用于已适配的会话、通讯录、搜索和朋友圈等界面，保留真实好友关系、消息及发布权限。微信消息通知和免打扰由微信及 iOS 原生设置管理。**后台模糊**另行配置，用于微信失去活跃状态时模糊页面。

**头像连点五下的快捷页不校验密码**：能操作已解锁手机的人可查看或修改密友配置，并经两次确认清空当前账号的密友配置。密友重置独立于普通“重置设置”，不删除微信好友或聊天记录。

### 广告净化与反检测

**界面定制 → 广告净化**的总开关及各范围默认关闭。开启总开关后选择需要处理的广告范围；“订阅号推荐内容”独立控制。更改后重新进入目标页面查看，搜一搜仅过滤带明确广告标记的结果。实际效果受微信版本与内容加载路径影响，当前安装包的广告净化仍待手机验收，详见[广告净化说明](docs/features/ad-purification.md)。

**账号与安全 → 防封检测**提供 28 项独立能力及接口、资源和实际调用诊断，默认关闭。部分变更需要重启微信，实验项有单独说明；接口匹配或测试通过不代表能够避免封禁。适用范围、限制与应急停用方式见[反检测说明](docs/features/client-guard.md)。

### 朋友圈布局

**界面定制 → 朋友圈布局**位于“广告净化”之后。“启用瀑布流布局”默认关闭，开启或关闭后退出当前朋友圈，再从“发现 → 朋友圈”重新进入，以便微信按当前开关选择页面入口。

开启后使用双列等宽卡片，按较短列依次排列；封面随图片比例调整并限制过高封面的展示高度，标题最多显示两行。正文下方按需显示浅底位置标签；底部圆形头像居左，半粗体备注名与其下方的发布时间叠放，点赞和评论数量靠右。多图仅取首张作封面并标注张数，视频显示播放标记并遵循微信网络设置静音自动播放，纯文字动态继续展示。点击整张卡片进入完整的微信原生详情查看图片、播放视频、点赞或评论，返回后保留原卡片附近的位置；顶部背景图延伸至卡片上方并向下渐隐，下拉刷新与加载更多继续接入原流程。

`2.7-6` 为转发的视频号直播补全分享封面、标题及主播来源；点击直播卡片进入微信原生朋友圈详情，再使用详情页的直播入口，不参加普通朋友圈视频的自动播放。小程序分享优先展示分享数据中明确提供的封面；没有封面、只有小尺寸图标时，改用图标、标题和小程序来源组成的紧凑卡片，避免将图标铺满大图区域。封面缺失时保留可读文字，小程序点击继续交给微信原生分享流程处理；不修改原始朋友圈媒体或发布内容。

`2.9-2` 将没有媒体和有效封面的 H5 链接改为紧凑卡片，显示链接图标、来源或域名以及主标题，不把完整长链接和编码参数作为封面文字。小程序卡片原粗体标题位置显示小程序名称，图标右侧或大封面下方的信息行显示分享页面标题；名称优先使用当前账号本地缓存，其次使用分享中的有效名称，均缺失时显示“小程序”，过滤固定占位“小程序名称”。原始链接、原生打开流程和朋友圈数据保留；实际视觉效果尚未真机验证。

密友朋友圈隐藏和互动过滤继续生效；启用“广告净化”的总开关与“朋友圈广告”范围时，瀑布流同时过滤明确标记的广告。布局开关为全局配置，支持备份与重置。beta05 将卡片圆角从 8pt 增至 14pt，全部卡片字体各增加 1pt，头像从 20pt 增至 28pt；作者名优先显示当前账号设置的联系人备注，没有备注时沿用昵称，更新列表时重新读取。此前的入场、返回与上下间距调整继续保留。当前包仍需在原设备复验字体、备注、位置及顶部渐隐效果，详见[朋友圈布局说明](docs/features/moments-layout.md)。

### 后台运行

**功能增强 → 后台运行**通过有限系统任务与单次短静音音频辅助后台执行。进入后台 `1.5` 秒后首次检查，默认每 `25` 秒检查，可设为 `10–30` 秒；微信通话、录音等自身音频优先，释放后再评估交接。

设置页可查看当前状态和本次后台过程的事件时间线，最多保留 `80` 条内存记录。该功能受 iOS 调度限制，不能保证持续驻留或唤醒已挂起进程。关闭它仍可利用微信已有执行机会处理自动回复和群事件；实际锁屏表现、耗电与温升需在设备原注入／签名环境确认。

## 配置与备份

聊天分组、密友、自动回复、AI、定时任务和群聊工具含按账号保存的配置；多数外观设置为全局配置。旧版无账号归属的分组需确认后手动导入当前账号。

进入 **备份配置**可创建、导入、导出、预览、重命名、收藏和删除备份。文件使用 `.wcbak` 格式，保存在微信应用容器的 `Library/Preferences/WeChatImprove/BackupV2/`。

**重置设置**位于 **备份配置 → 恢复管理**。进入后选择重置范围、预览并确认计划，完全退出并重新打开微信后应用；执行前可在备份页取消计划。

**修复当前的配置**提供自定义图片及联系人分隔图片的修复入口。重新选择图片或移除无效引用后，返回备份页重试。

- **保存范围**：已登记的插件配置、自定义图片、已存档账号分组及当前账号的相关功能配置；账号数据保留原归属。
- **手动保存**：修改配置、升级、恢复和重置不会额外创建备份，也不按数量清理历史文件，需要保留当前配置时先手动创建。
- **恢复步骤**：选择模块与所属账号 → 查看差异 → 准备恢复计划 → 完全退出并重新打开微信 → 校验和应用。导入文件或准备计划后尚未应用设置。
- **恢复后检查**：定时任务与自动功能恢复后需重新检查并启用；AI 还需重新设置 API Key 并测试连接。群聊工具重建成员基线，不恢复待发欢迎或批量退群任务。
- **文件内容**：不包含微信聊天记录、登录凭据、AI API Key、支付账本或待发送任务。文件未加密，可能包含联系人标识、分组成员与自定义文字。

仅支持当前 `.wcbak` 格式。图片缺失或损坏时，在对应设置页修复引用后重新备份；恢复事务正在使用的文件，需先取消计划或完成恢复／回滚后再删除。

## 源码编译

需要 macOS、Xcode、可用的 iPhoneOS SDK、[Theos](https://theos.dev/docs/installation) 及对应方案的打包工具。保留完整的 `Headers/` 和 `HeadersFile/` 私有接口声明。

```bash
git clone https://github.com/ZhangSCzybh/WeChatImprove.git
cd WeChatImprove
xcrun --sdk iphoneos --show-sdk-path

# Rootless
make package -j4 THEOS="$HOME/theos" SCHEME=rootless \
  PACKAGE_VERSION="$(awk '/^Version:/{print $2}' control)"

# Rootful
make package -j4 THEOS="$HOME/theos" SCHEME=rootful \
  PACKAGE_VERSION="$(awk '/^Version:/{print $2}' control)"
```

Makefile 内含开发机的固定 Theos 路径，命令中应显式传入本机实际 `THEOS` 路径。上述示例从 `control` 读取版本，构建产物默认位于 `packages/`。Roothide 使用 `SCHEME=roothide`，需安装匹配的 Theos 方案支持。

> `make clean` 会删除整个 `.theos/` 和 `packages/`，包括已有安装包与调试符号。清理前先将需要保留的产物保存到这两个目录之外。

发布时同步维护 `control`、`Headers/CSUserInfoHelper.h` 中的 `kPluginVersionString` 和 `Controllers/CSReleaseNotesViewController.m`。`PACKAGE_VERSION` 仅覆盖当次包版本，不会更新插件内版本；可用 `dpkg-deb -f <安装包路径> Version Architecture` 核对产物元数据。

## 常见问题

| 问题               | 排查方式                                                    |
| ---------------- | ------------------------------------------------------- |
| 找不到插件入口          | 默认在“我 → 设置 → 再也不会”；修改过名称或位置时按实际设置查找，并确认安装方案与注入生效        |
| 分组栏不显示           | 检查总开关、登录状态与微信版本，退出搜索／编辑状态后返回聊天列表，必要时重新打开微信              |
| 横滑无法打开会话菜单       | 从会话列表最右侧 `15%` 区域起手左滑，或关闭“分组切换手势”                       |
| 切换账号后分组不同        | 分组按账号保存，旧版分组需在设置页手动导入当前账号                               |
| 恢复后设置没有变化        | “准备恢复”只保存计划，需完全退出并重新打开微信                                |
| 后台回复或定时任务延迟      | 检查功能开关、会话名单、授权及执行条件；微信被挂起时无法实时处理                        |
| 包版本与插件显示版本不同     | 核对 `control`、`kPluginVersionString` 和 `PACKAGE_VERSION` |
| 编译找不到 Theos 或头文件 | 显式指定本机 `THEOS` 路径，检查头文件目录与 `xcrun` 使用的 SDK              |

问题反馈请附插件版本、微信实际版本、iOS 版本、注入环境、相关开关及复现步骤；界面问题可附遮挡个人信息后的截图，崩溃问题可附日志。反馈入口：[GitHub Issues](https://github.com/ZhangSCzybh/WeChatImprove/issues)。

本项目用于学习和研究 iOS 界面定制与 Runtime Hook。感谢 Theos 等开源工具及贡献代码、测试和反馈的使用者。

## 小丑功能新增能力（2.7-0-beta01）

- **你别冷漠好不好**：开启小丑总开关和该项后，通过微信原生多选器配置「生效联系人」「生效群聊」。空名单不生效，名单按微信账号分别保存。仅匹配对方发送的纯文本 `嗯、奥、恩、嗷、嗷嗷、行、好、可以、可、成、ok、OK`，在本机随机显示热情表达；同条消息在当前会话内保持一致。自己发送的消息、带标点或空格的其他文本不处理，手动修改优先。
- **假的引用好玩吗**：输入 `#假引用 被引用的内容；真正发送的内容`，也支持半角分号 `;`。指令后使用空格，不使用加号；以第一个分号拆分，正文后续分号原样保留。仅分号后正文交给微信发送，本机显示带当前昵称的引用灰条。格式错误、空引用、空正文、已有真实引用或原生 @ 成员时保留草稿并提示。

两项默认关闭，可独立使用，不依赖「聊天文字修改」开关；受小丑总开关控制。临时文案和假引用只在当前聊天页内存中存在，离开会话或切换账号后清除；原始消息不因本地展示而变化。复制、转发和搜索继续读取真实内容。配置备份包含开关和生效名单，不包含临时显示；关系名单按已有备份规则限制为同一本机来源和同一当前账号恢复。

详见 [功能说明](docs/features/clown-chat-effects.md) 与 [本版产物说明](packages/2.7-0-beta01/README.md)。
