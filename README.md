# WeChatImprove

面向 iOS 微信的 Theos 插件，使用 Objective-C / Logos 接入微信原生界面，提供聊天分组、界面定制、消息增强、自动回复和配置备份等功能，可在插件设置中按需开启。

**源码版本：`3.0-3`（完整版，含全部既有模块）** · **架构：`arm64` / `arm64e`** · **最低编译目标：iOS 15.0**

## 安装与入口

需要能够向微信加载插件的 iOS 注入环境。近期适配参考为微信 `8.0.78`、`8.0.80`，广告净化等私有接口以 `8.0.80.34` 为核验依据；这不代表所有系统、微信版本及插件组合均已通过真机验证。安装包声明依赖 `mobilesubstrate >= 0.9.5000`。

当前源码与完整构建版本为 **3.0-3**。整合五处设置预览、聊天分组与列表圆角的设置分类、文本占位与朋友圈预览修正，以及底栏功能键背景和图标独立配色。功能键配色默认跟随原生，两项均可独立恢复默认，实际底栏与预览同步更新，并支持备份、恢复及重置。**本轮完成核心主机回归与双方案完整编译，实际设备画面和触摸体验仍需验收。**

本版包含全部既有功能。完整产物按现有注入环境选择：

<br />

1. 使用设备上适配当前环境的包管理器或安装工具安装，并按工具提示重新加载注入环境。
2. 完全退出并重新打开微信，进入 **我 → 设置 → 再也不会**。
3. 按页面提示完成公众号关注验证和首次使用声明，再开启所需功能。

默认入口名称为“再也不会”。在 **入口设置** 中可修改名称，或改为显示在“我”页面、微信设置页及已有插件管理入口；后者需要宿主环境提供 `WCPluginsMgr`。

## 使用说明

以下路径均从插件设置首页进入，按需开启功能并遵循页面提示。部分外观设置提供示例预览。

### 首页顶部信息

显示当前账号信息、随机文案、已开启功能数量，以及插件和微信版本。

### 聊天分组与外观

相关入口位于 **界面定制**。

- **聊天分组**：管理预设组和自定义组，支持成员管理、排序、隐藏、未读角标、搜索及横滑切换。
- **气泡样式**：调整聊天气泡圆角和浅深色收发配色。
- **连续消息合并**：合并连续消息的展示，设置头像保留方式和消息间距。
- **列表圆角**：自定义会话、通讯录、发现和“我”页面的卡片圆角、边距及背景。
- **底栏样式**：提供经典悬浮、分离功能键、居中功能键三种结构，可调整尺寸、图标、文字和配色。
- **顶栏信息**：自定义聊天顶栏的显示内容，并通过预览查看效果。

### 消息与语音

- **文本占位**：在 **界面定制 → 文本占位** 中调整输入框样式，并为左右滑配置清空、复制、剪切、粘贴或发送等操作。
- **消息手势**：在 **功能增强 → 消息手势** 中，为己方和对方消息分别设置左右滑动作，如引用、转发、收藏或复读。
- **语音转发**：分别控制聊天语音转发、收藏语音转发和播放进度拖动。
- **表情功能**：支持将聊天图片添加到表情。
- **小丑功能**：临时修改文字、时间、图片和转账等本地显示，离开聊天页面后恢复。

### 自动回复、AI 与定时任务

相关入口位于 **功能增强**，可按账号配置生效会话或目标。

- **自动功能**：支持拍我回拍、拍我回复、@我回复和关键词回复，可设置会话名单与执行延迟。
- **人工智能**：配置服务和模型后，为指定会话启用 AI 回复，支持多预设和图片识别；相关消息会发送至所配置的服务。
- **定时任务**：向指定私聊、群聊或文件传输助手定时发送文字，支持单次、周期和时间段规则。
- **群聊功能**：提供入群欢迎、退群提示、自动保存到通讯录和批量退群。

自动回复和定时执行受微信运行状态及 iOS 调度限制。

### 快捷面板

进入 **增强 Tab → 快捷面板**，可设置从微信主页底栏或聊天输入框上滑打开。面板显示账号与时间日期，提供 21 个可选快捷入口，支持入口排序及背景、字体和图标配色。

### 密友与隐私

- **捉迷藏呀**：在插件首页长按头像发现入口，设置独立密码后管理密友和密群，支持临时显示及自动隐藏；隐藏作用于已适配界面，保留真实好友关系和聊天记录。
- **后台模糊**：在微信失去活跃状态时模糊页面内容。

### 广告净化与反检测

- **界面定制 → 广告净化**：按范围过滤公众号、订阅号、朋友圈、视频号、小程序和搜一搜广告，支持独立控制订阅号推荐内容。详见[广告净化说明](docs/features/ad-purification.md)。
- **账号与安全 → 防封检测**：提供反检测设置及接口、资源和调用诊断，不能保证避免封禁。详见[反检测说明](docs/features/client-guard.md)。

### 朋友圈布局

在 **界面定制 → 朋友圈布局** 中启用双列瀑布流卡片，支持图片、视频、文字和分享内容，保留微信原生详情与互动入口。详见[朋友圈布局说明](docs/features/moments-layout.md)。

### 后台运行

**功能增强 → 后台运行**通过有限系统任务和短静音音频辅助后台执行，可查看运行状态与事件记录；受 iOS 调度限制，不能保证持续驻留。

## 配置与备份

聊天分组、密友、自动回复、AI、定时任务和群聊工具含按账号保存的配置；多数外观设置为全局配置。旧版无账号归属的分组需确认后手动导入当前账号。

进入 **备份配置**可创建、导入、导出、预览、重命名、收藏和删除备份。文件使用 `.wcbak` 格式，保存在微信应用容器的 `Library/Preferences/WeChatImprove/BackupV2/`。

**重置设置**位于 **备份配置 → 恢复管理**。进入后选择重置范围、预览并确认计划，完全退出并重新打开微信后应用；执行前可在备份页取消计划。

**修复当前的配置**提供自定义图片及联系人分隔图片的修复入口。重新选择图片或移除无效引用后，返回备份页重试。

- **保存范围**：已登记的插件配置、自定义图片、已存档账号分组及当前账号的相关功能配置；账号数据保留原归属。
- **手动保存**：修改配置、升级、恢复和重置不会额外创建备份，也不按数量清理历史文件，需要保留当前配置时先手动创建。
- **恢复步骤**：选择模块与所属账号 → 查看差异 → 准备恢复计划 → 完全退出并重新打开微信 → 校验和应用。导入文件或准备计划后尚未应用设置。
- **恢复后检查**：定时任务与自动功能恢复后需重新检查并启用；AI 还需重新设置 API Key 并测试连接。群聊工具重建成员基线，不恢复待发欢迎或批量退群任务。
- **文件内容**：不包含微信聊天记录、登录凭据、AI API Key、支付账本或待发送任务。文件未加密，可能包含联系人标识、分组成员与自定义文字。

仅支持当前 `.wcbak` 格式。图片缺失或损坏时，在对应设置页修复引用后重新备份；恢复事务正在使用的文件，需先取消计划或完成恢复／回滚后再删除。

## 源码编译

需要 macOS、Xcode、可用的 iPhoneOS SDK、[Theos](https://theos.dev/docs/installation) 及对应方案的打包工具。保留完整的 `Headers/` 和 `HeadersFile/` 私有接口声明。

```bash
git clone https://github.com/ZhangSCzybh/WeChatImprove.git
cd WeChatImprove
xcrun --sdk iphoneos --show-sdk-path

task_version=$(awk '/^Version:/{print $2}' control)
task_project=$PWD
task_build_root=$(mktemp -d "${TMPDIR:-/tmp}/wechat-${task_version}.XXXXXX")

for task_scheme in rootless rootful; do
  make package -j4 THEOS="$HOME/theos" SCHEME="$task_scheme" \
    _THEOS_LOCAL_DATA_DIR="$task_build_root/build-$task_scheme" \
    _THEOS_SWIFT_AUXILIARY_DIR="$task_build_root/swift-$task_scheme" \
    THEOS_PACKAGE_DIR="$task_project/packages/$task_version" \
    PACKAGE_VERSION="$task_version" PACKAGE_BUILDNAME= \
    DEBUG=0 FINALPACKAGE=1 KEEP_LOGOS_INTERMEDIATES=1 || exit $?
done
```

Makefile 内含开发机的固定 Theos 路径，命令中应显式传入本机实际 `THEOS` 路径。上述命令从 `control` 读取本版版本，为两种方案分别使用独立临时构建目录，完整产物写入 `packages/3.0-3/`，保留调试符号与 Logos 中间文件。本轮提供 Rootless、Rootful 完整包及与 Rootful 包内一致的重签动态库。Roothide 使用 `SCHEME=roothide`，需安装匹配的 Theos 方案支持。

> `make clean` 会删除整个 `.theos/` 和 `packages/`，包括已有安装包与调试符号。清理前先将需要保留的产物保存到这两个目录之外。

发布时同步维护 `control`、`Headers/CSUserInfoHelper.h` 中的 `kPluginVersionString` 和 `Controllers/CSReleaseNotesViewController.m`。`PACKAGE_VERSION` 仅覆盖当次包版本，不会更新插件内版本；可用 `dpkg-deb -f <安装包路径> Version Architecture` 核对产物元数据。

## 常见问题

| 问题               | 排查方式                                                    |
| ---------------- | ------------------------------------------------------- |
| 找不到插件入口          | 默认在“我 → 设置 → 再也不会”；修改过名称或位置时按实际设置查找，并确认安装方案与注入生效        |
| 分组栏不显示           | 检查总开关、登录状态与微信版本，退出搜索／编辑状态后返回聊天列表，必要时重新打开微信              |
| 横滑无法打开会话菜单       | 从会话列表最右侧 `15%` 区域起手左滑，或关闭“分组切换手势”                       |
| 切换账号后分组不同        | 分组按账号保存，旧版分组需在设置页手动导入当前账号                               |
| 恢复后设置没有变化        | “准备恢复”只保存计划，需完全退出并重新打开微信                                |
| 后台回复或定时任务延迟      | 检查功能开关、会话名单、授权及执行条件；微信被挂起时无法实时处理                        |
| 包版本与插件显示版本不同     | 核对 `control`、`kPluginVersionString` 和 `PACKAGE_VERSION` |
| 编译找不到 Theos 或头文件 | 显式指定本机 `THEOS` 路径，检查头文件目录与 `xcrun` 使用的 SDK              |

问题反馈请附插件版本、微信实际版本、iOS 版本、注入环境、相关开关及复现步骤；界面问题可附遮挡个人信息后的截图，崩溃问题可附日志。反馈入口：[GitHub Issues](https://github.com/ZhangSCzybh/WeChatImprove/issues)。

本项目用于学习和研究 iOS 界面定制与 Runtime Hook。感谢 Theos 等开源工具及贡献代码、测试和反馈的使用者。
