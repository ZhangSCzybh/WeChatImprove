# 1.6-15：气泡外观判定与支付卡片配色移除

目标：微信 8.0.78.34 / Rootless，用户设备报告 iOS 27.0.1。当前 checkout 延续原项目，工作分支 codex/bubble-appearance-fix。

## 浅色配置失效的逻辑

旧适配器优先读取微信私有 isUseLightStyle，并将其取反作为深色模式标志；只要该方法存在，就不会读取 cell.traitCollection。私有标志为 NO、UIKit 视图为 Light 时，旧代码选择深色配色，与用户报告现象一致。头文件只提供该私有方法声明，不足以证明它与 UIKit 深色模式互为反值。

设置页浅色/深色发送方/接收方的保存键与策略读取键一致，没有交换。修复只更正外观来源：优先使用聊天视图的 userInterfaceStyle；仅当 Unspecified 时，依次使用所属 window、当前 UITraitCollection；均未指定时使用浅色。这样尊重微信界面自身的外观覆盖，不直接使用全局手机模式，也不查找其他 window。

现有 traitCollectionDidChange、原生背景更新和布局入口会使用新的外观判定；模板缓存和原生重复图片赋值的快捷路径共用同一判定，防止切换后沿用旧主题。不增加定时器、全页面扫描或新刷新机制。

## 移除红包/转账颜色

- 设置页去除浅色和深色模式下的发送方/接收方红包转账颜色项，以及预览、配置键定义、颜色读取/保存、选择器分支、默认值和重置逻辑。
- 气泡配置只保留四组普通颜色，删除 payment 参数与四组支付卡片颜色。
- 适配器删除支付信息识别、支付专用背景处理及缓存维度。只支持普通文本、引用文本及语音，红包和转账保持原生背景。
- 删除仅为原支付分支保留的完整轮廓测量入口；普通气泡使用既有正文轮廓算法。
- 历史偏好值不再读取或写入，不主动删除设备设置；旧键存在也不会改变有效配置快照。其他红包领取、转账处理功能属于独立功能，不在本次移除范围。

README 功能概览同步更新。历史版本文档保留当时行为。

## 验证

先加入“UIKit Light + isUseLightStyle NO”的真实模板像素断言，旧适配器失败，修复后通过。

- 8,269 项策略、渲染、图片所有权断言通过。移除了已下线的 payment 组合，断言数量随之减少；增加旧支付偏好不影响普通配置的验证。
- 111 项实际适配器生命周期断言通过，包含不同主题/收发方向的明确色值、普通/引用/语音背景像素、高亮图片、私有标志冲突、视图优先于窗口、Unspecified 回退、运行时主题切换、编辑非当前主题不改变当前颜色、当前主题修改生效、重复赋值缓存以及红包/转账保持原生图片。

未安装到设备，未读取聊天数据库或写入设备设置，旧安装包全部保留。

## 设备复核

安装 1.6-15 并完全退出/重开微信。在微信聊天页面为浅色时，将浅色的发送方/接收方颜色设为明显不同的颜色，确认对应普通消息更新；仅修改深色配置不应改变浅色聊天。切换到深色聊天后确认使用深色配置，再切回浅色。微信若设置了独立外观，以聊天页实际外观为准。

确认浅色/深色区域各剩普通发送方和接收方两项，红包及转账卡片显示原生背景，并检查引用消息、多行文本、消息合并下的气泡显示。
