# 1.6-3 气泡与防撤回重构交付

日期：2026-10-16。目标：微信 8.0.78 / Rootless，arm64 + arm64e，最低编译目标 iOS 15。
状态：源码和本地回归已完成，测试包已生成；未连接设备、未安装、未触及微信账号、配置或聊天数据库。不能据此声明真机问题全部解决、零卡顿或低耗电达标。

## 气泡

旧实现全局修改 BubbleInfo 图像。当前实现按真实消息 Cell 的 `getBgImageView` 绑定背景，处理 YYAsyncImageView 自己保存的 YYImage 槽位与异步解码后重新赋图，避免只替换 UIImageView.image 却未进入微信实际绘制链路。

保留项目的八组配色和圆角设置；普通文本、分段文本、语音、可明确识别的红包/转账背景进入适配。通过 Core Graphics 小模板绘制，保留原生透明外围、scale 和拉伸方式。未知卡片、媒体、动画背景、解码尚未完成或布局/接口无法确认时保留原生外观，不强行着色。特殊品牌支付背景不保证适配。

背景绑定保存原图与本模块所有权；微信重新赋图、设置变更、外观变化触发按需更新，关闭和复用时恢复。本模块不修改消息行高、头像显示或时间标签。NSCache 限制 128 项、8 MiB；这是缓存逐出限制，不等于整个模块总内存硬上限。

## 防撤回与持久链接

结构化解析撤回 XML，核对原消息服务端 ID 和会话归属后决定保留。插入装饰性提示失败或抛出异常，不再撤销已经确认的保护决定。事件按账号/会话/服务端 ID 去重，上限 512 条。自撤回文本使用完整匹配，并核对原文发送方，避免昵称包含自撤回短语而误判。替换/删除入口也经过同一验证，不再无条件吞掉未知事件。

新提示把 `revoke_jump_v2_<serverID>_<localID>` 写入可点击正文，仍兼容历史 `revoke_jump_<serverID>`；pattern 作为兼容来源。正文可以恢复引用，运行不依赖旧 Cell 的关联对象。来源冲突、非法数字、账号/会话不符拒绝跳转；普通链接交还微信。

每次页面创建/显示重新绑定所属聊天；私聊接收方为当前账号、群聊会话、旧提示缺失部分字段分别验证。原文查找只发生在点击时，历史加载沿用微信接口。导航等待表格事务和合并布局完成，最多一次坐标修正，再核对目标节点与实际可见 Cell 的消息身份。

目标使用页面覆盖层短暂显示橙色描边和淡色标记，约 1.2 秒，不修改原气泡图像或行高。支持减弱动态效果和 VoiceOver。拖动、离页、新请求、消息增删/重载及目标布局变化取消标记。不存在持续轮询或显示刷新定时器；每个未完成导航仅有一个可取消的 8 秒截止计时器。

隐藏撤回提示仅作用于识别出的本插件提示，普通系统消息保持原生。解析按模型与内容缓存，设置变化使相关布局失效以恢复高度。

## 与消息合并、时间和头像的关系

聊天桥接从合并适配器提取为独立模块。关闭合并不关闭气泡或防撤回导航。合并仍负责相邻消息关系和安全间距，导航请求期间不与合并锚点争抢滚动位置。

补齐消息时间的时间戳读取与格式化辅助函数，遵守原有年/月/日/时/分/秒和换行设置；按线程复用日期格式器，格式化不创建后台 UI 任务。原文标记不强制恢复隐藏头像、不更改时间标签点击状态。

这些边界降低相互覆盖风险，不能替代微信真机组合测试。

## 真机验收顺序

1. 安装此测试包并确认插件显示 1.6-3，在原账号/原聊天记录中测试。
2. 普通文本、语音分别验证己方/对方气泡配色和圆角，切换深浅色；关闭气泡后应恢复原生。
3. 私聊和群聊各测试新撤回提示首次点击：定位原文并显示短暂标记。
4. 退出重进，点击同一条提示；再次重进以及微信进程重启后重复。旧 1.6-2 有效蓝字提示也应验证。
5. 组合开启/关闭消息合并、隐藏头像、消息时间与隐藏撤回提示，确认间距、时间和其他系统消息。
6. 原文需要加载历史、已删除、连续点击不同链接、跳转中拖动、键盘打开、长文本与图片原文分别检查。
7. 在同一设备/账号/聊天数据/其他插件配置下做开关 A/B，测量滚动卡顿、CPU、内存和能耗；本地没有这些测量数据。

如仍有问题，在插件「防撤回」设置中开启「兼容性诊断」，分别复现私聊/群聊的首次点击与退出重进，再选择「复制诊断记录」。记录包含插件/iOS/微信版本与最多 128 条阶段事件，不记录消息正文、账号、联系人或消息 ID。测试后可关闭诊断。该记录用于定位入口是否命中、引用校验、查询与标记阶段，不能替代崩溃日志或帧耗时测量。

原有 1.5-7、1.6-0、1.6-1、1.6-2 包全部保留。关闭某项功能不等于整包回退。
