# 小丑功能：当前聊天的本地显示修改

源码版本：`2.3-6`。入口为 **插件设置 → 功能增强 → 小丑功能**，位于“表情功能”下方；页面使用与其他功能设置相同的分组、单元格和导航布局。

此功能在本机当前聊天页面临时显示替换内容，离开聊天会话后恢复原样。覆盖内容只保存在内存中，不上传，也不写入原始消息对象、微信聊天数据库、原图片文件或支付状态。

## 开关与使用方式

总开关和四个子开关首次全部关闭。先开启“开启小丑功能”，再开启需要的子项；关闭总开关会隐藏子项并保留它们的选择，同时恢复已替换的显示。重新开启后需要重新修改消息，之前的临时内容不会恢复。

| 子开关 | 操作 | 生效范围 |
| --- | --- | --- |
| 聊天文字修改 | 长按普通文字消息，选择“修改文字”，输入内容后点“确定” | 当前消息气泡的本地文字显示 |
| 聊天时间修改 | 长按聊天消息之间的系统时间标签，输入时间后点“确定” | 当前系统时间标签的本地显示 |
| 聊天图片修改 | 长按普通图片消息，选择“修改图片”，从系统相册选择一张图片 | 当前图片消息气泡的本地显示 |
| 聊天转账修改 | 长按转账消息，选择“修改金额”，输入金额后点“确定” | 当前转账气泡的金额显示 |

取消文字、时间、金额弹窗或相册选择，不应用本次修改。插件自己的编辑弹窗和相册选择流程允许完成当前编辑；返回聊天列表、进入其他页面或切换账号会结束当前会话的临时显示。滚动造成的气泡复用不会把替换内容带到其他消息；重新进入该聊天时使用原始内容。

“聊天时间修改”针对微信原生系统时间标签，与“信息时间”功能显示的每条消息时间分别处理。它不调整消息的实际发送时间、排序或聊天历史。“修改金额”仅替换显示金额，不改变真实转账金额、收款／退还状态、支付记录，也不触发支付操作。复制、转发等微信原有动作仍读取原始消息内容。

## 输入规则

时间严格使用 `yyyy-MM-dd HH:mm`，例如 `2026-11-09 14:30`。按设备当前时区解析。点击系统时间时继续使用微信原生的整页模式切换：简略模式显示为 `11月9日 14:30`，详细模式显示为 `11月9日 星期一 14:30`，两种格式均以替换后的日期计算。无效日期、尾随字符以及夏令时跳过的不存在时刻不能确认。

金额使用十进制数字键盘。输入必须为 1–9 位 ASCII 整数，可附 1–2 位小数，并且大于零，最大 `999999999.99`。确认后统一为两位小数，例如 `12` 显示为 `12.00`，`0012.3` 显示为 `12.30`。`0`、负数、加号、科学计数、千位分隔符和尾随字符均不接受；无效输入时“确定”不可用。

## 数据与恢复边界

总开关及四个子开关按现有插件偏好方式保存，并登记到备份的“消息操作”模块。消息替换内容、所选图片和临时金额不进入配置备份，不跨聊天页面或微信进程保留。

替换通过页面内存和展示视图完成，原消息 wrap、视图模型正文、数据库、原图片与支付信息保持原值。关闭相关子开关会清除该类临时内容；关闭总开关、退出会话或切换账号会清除整个临时会话。已离开页面后才返回的相册结果或旧编辑确认不会应用到新的会话。

## 验证状态

用户对已交付的 `2.3-5` 进行了实际使用反馈，发现转账“修改金额”菜单以及系统时间显示、点击切换存在问题；原版主机检查没有覆盖这些真实交互缺陷。本轮 `2.3-6` 兼容转账标题中的纯数字、千分位与币种格式，避免金额识别失败时过滤“修改金额”菜单，并保留原生时间点击链和整个聊天页的时间模式切换。

真实 UIKit 检查确认，直接修改原生视图 backing layer 的透明度会同时影响 `UIView.alpha` 和点击命中。本轮改为保存并临时替换原生 layer mask，遮住原显示而保留原生视图的触摸响应；退出、复用及关闭功能时恢复原 mask。替换时间根据微信原生 `isNeedShowTimeInDetail` 模式更新简略与详细格式，原生 `toggleTimeShowMode:` 仍执行自己的切换。接口类型依据微信 `8.0.80` 的[已有静态元数据](../audits/wechat-8.0.80-followup-2026-11-09/revoke/page-native-methods.json)核对。

本轮小丑功能 1115 项检查通过（偏好 249、菜单 302、会话 120、布局 116、真实 UIKit 展示 328），既有消息手势、消息时间和消息动作执行共 3089 项回归通过。两条已替换的系统时间能够随一次原生模式切换同时更新，使用各自的新日期计算星期。旧版原始构建快照的两组反向检查复现了金额菜单缺失和时间点击命中失效；本轮检查通过，详见[修复记录](../audits/clown-menu-time-fix-2026-11-09/README.md)。

Rootless／Rootful 构建及产物核对完成。真实 UIKit 展示检查运行于 Mac Catalyst，微信类与相册边界使用替身；时间测试在真实 hitTest 后调用私有回调替身，没有注入真实触摸事件。`2.3-6` 尚未在 iPhone 微信复验，实际菜单、两种时间格式的切换及与其他插件的组合仍需确认。

`2.3-5` 的历史构建结果保留，见[原构建结果](../audits/clown-local-display-2026-11-09/build-result.json)与[原构建命令](../audits/clown-local-display-2026-11-09/build-commands.json)。这些记录对应旧版，不能作为本轮修正版的验证结论。
