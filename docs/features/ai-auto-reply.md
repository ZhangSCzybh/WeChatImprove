# AI 自动回复

基于现有 Theos / Objective-C / Logos / UIKit 框架实现，使用插件设置样式和微信原生聊天详情分组。功能按微信账号隔离，总开关与每个会话开关默认关闭。

## 使用步骤

1. 打开「插件设置 → 功能增强 → 人工智能」。
2. 在「模型连接」填写兼容 Chat Completions 的完整 HTTPS 请求地址、API Key 和模型名称，点击「保存」。例如地址形态为 `https://服务域名/v1/chat/completions`，不会自动补齐路径。
3. 配置服务商与能力后点击「测试连接」。默认发送固定短消息；开启图片识别后发送固定 32×32 合成图文，不读取微信图片。确认接口接受当前配置且返回非空文本，不发送微信消息或自动开启总开关。地址、模型、Key 或能力变化后需重新测试；再次测试失败撤销旧验证，取消测试保留已有验证。连接成功不代表图片识别准确率，也不证明本次实际执行了搜索。
4. 在「管理预设」新增、编辑或复制多个命名预设。提示词用于定义角色、语气和回复规则。选择全局默认预设；删除预设时选择替代项并更新会话引用，至少保留一个预设。
5. 开启总开关，进入某个聊天窗口右上角「…」的聊天详情，群聊在「查找聊天内容」下方开启「启用 AI 回复」，并通过「回复预设」选择跟随默认或独立预设；私聊仍使用「AI 回复」分组。
6. 群聊需要免 @ 自动回复时，打开「启用 AI 回复」正下方的「免 @ 回复」。该开关默认关闭，仅对当前群生效；也可在「已开启的会话」中进入该群修改。仍需总开关和当前群的 AI 开关同时开启。
7. 群聊设置「消息免打扰」后仍需后台免 @ 回复时，开启插件的「后台运行」，确认显示「后台音频已启动」。修复版在后台保活实际有效且 AI 连接已验证时，约每 30 秒请求一次微信原生消息同步；不修改群免打扰设置。该行为会增加网络活动与耗电，关闭后台运行、AI 总开关或最后一个免 @ 群的相关开关后停止。

群聊的三行设置按「启用 AI 回复 → 免 @ 回复 → 回复预设」排列，与「查找聊天内容」使用同一个原生分组，复用微信的开关行、右值箭头行、分隔线和默认间距，不另外增加标题或长篇页脚。开启会话后，连接待验证、总开关关闭等状态使用原生行内说明展示。

设置页可查看已开启会话与最近 200 条回复记录。记录展示时间、会话、预设、结果和简短原因；不保存聊天正文、模型回复或 API Key。「已提交微信」只表示微信原生发送调用正常返回，不代表对方已收到。

「密友 → 保护选项」中的「隐藏自动回复」，默认关闭。开启后，在密友功能启用且锁定时，「回复管理 → 已开启的会话」隐藏密友名单及密友群聊名单内的会话，入口数量仅统计可见会话；解锁后重新显示，重新锁定后再次隐藏。已打开的列表随隐私状态变化刷新。此选项与「隐藏聊天会话」「隐藏定时任务」独立，保留每个会话的启用状态和预设。只影响列表和数量展示；即使同时开启“隐藏聊天会话”，已启用会话仍正常自动回复。锁定、解锁或切换隐藏选项不会取消正在生成／排队的回复，也不会清空 AI 上下文。

## 百炼联网、图片与更换模型

当前 Qwen3.8-Flash 推荐设置：服务商选择「阿里云百炼」，模型填写 `qwen3.8-flash`，保留同一地域和业务空间的完整 Chat Completions 地址与 Key；开启「图片识别」，联网选择「按需联网」，「思考模式」保持关闭。插件不会自动替换域名、地域或请求路径。联网和图片需要模型、地域与账号权限支持。

| 设置 | 行为 |
| --- | --- |
| 通用兼容接口（默认） | 保持原来的文本非流式请求；支持显式开启图片。联网与思考关闭，不发送百炼专有字段 |
| 阿里云百炼 | 使用同一个 Chat Completions 地址，接收 SSE，将最终正文合并后只发送一条微信回复 |
| 联网关闭 / 按需联网 / 每次联网 | 分别关闭搜索、允许服务按问题判断、要求服务搜索；百炼采用 `turbo` 策略 |
| 图片识别 | 默认关闭；开启后发送符合规则的单张图片及问题。每批最多一张，不支持图集、语音、视频或引用消息解析 |
| 思考模式 | 默认关闭，以控制回复时间；开启需要模型支持，推理内容不会发送到微信 |

私聊与免 @ 群可直接发图；需要 @ 的群，先发图，再由**同一发送者在 30 秒内单独 @ 当前账号并提问**。仅暂存最新图片的有限身份与 wrap 引用，未触发前不读图、不下载、不调用模型。过期、其他人 @、@所有人不附带该图片；消息与原生身份无法可靠匹配时不上传。

图片处理在后台单串行队列完成，最长边缩至 2048、编码文件最多 2 MiB；原始输入最多 32 MiB、1 亿像素。缺图或本地文件无法解码时，最多请求一次微信静默下载，通常最多等待 20 秒；下载后仍无效则结束。图片准备与模型请求共用最多两个活动会话、60 秒活动时限和 120 秒总时限。图片仅用于当前请求，不保存在聊天上下文、配置、记录或备份，也不在后续文字回复中重复上传。

若显示「处理失败」，点击回复记录可查看图片下载、解码、模型请求或网络失败等固定说明。历史不保存服务端错误正文或图片路径；旧失败消息不会自动补发，安装修复后请重新发送新消息。最新候选同时兼容完整 JPEG/PNG 真实结束标记后的附加数据，仍拒绝缺失结束或结构损坏的图片。实际 JPEG 复现、核心回归和真机边界见 [格式完整性修复记录](../audits/ai-image-container-2026-10-28/README.md)，此前一次下载恢复见 [图片恢复记录](../audits/ai-image-recovery-2026-10-28/README.md)。

更换为另一个百炼模型时，修改模型名并按该模型文档关闭不支持的能力，再测试连接；换到其他兼容服务时，选择「通用兼容接口」并填写对应的完整地址、模型和 Key。通用接口仅声明文本和显式图片能力；其他厂商联网需要以后增加对应适配。切换能力会撤销连接验证并取消原任务，防止旧请求向新配置发送回复。

依据官方文档：[Qwen3.8-Flash](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[联网搜索](https://help.aliyun.com/zh/model-studio/web-search)、[Chat Completions 参数](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[视觉理解](https://help.aliyun.com/zh/model-studio/vision)、[思考模式](https://help.aliyun.com/zh/model-studio/deep-thinking)、[地域与接入点](https://help.aliyun.com/zh/model-studio/regions)。本次不追加推测的来源链接；搜索是否执行及费用以服务端记录为准。

## 回复规则

- 普通私聊处理符合条件的新文本消息，以及显式开启图片后的新图片消息。群聊默认必须在结构化 @ 名单中精确包含当前账号，手打 `@名字` 不算真实 @；当前群开启「免 @ 回复」后，普通新文本无须 @ 即可触发。`@所有人`、仅有 @ 没有正文仍不触发。
- 「免 @ 回复」按账号和群聊单独保存。修改回复预设、临时关闭再开启该群 AI 会保留此偏好；旧配置缺少此字段时按关闭处理。
- 本人消息、历史消息、重复消息、系统消息、公众号/服务号和未支持的消息类型不触发。
- 同一会话同一发送者的连续消息等待 2 秒后合并。同一会话串行处理，全局最多 2 个活动会话（含图片准备），最多等待 20 批；排队批次 120 秒过期，单次请求 60 秒超时。
- 模型上下文仅包含启用之后产生的内存对话，最近最多 10 条、正文总计最多 12000 个 UTF-16 单元；群按群与发送者分开。预设系统提示词另计。回复最多 4000 个 UTF-16 单元，不拆分发送。
- 手动回复与 AI 自动回复可以并行。手动发送消息不会取消或暂停 AI 任务，不会清空 AI 对话上下文；正在生成或排队的 AI 回复会继续处理。
- 关闭 AI 开关、修改 AI 配置或切换账号，会取消尚未提交的任务。密友锁定／解锁及隐藏选项变化只刷新展示，不暂停回复。配置保存统一取消当前待回复任务并清空上下文。已经交给微信的消息无法通过关闭开关撤回。
- 首次启动、重新开启或清空运行状态后不补回复旧消息。由于微信时间戳精度为秒，开关变化所在那一秒的新消息可能被保守跳过。
- 已处理身份在本机持久化，服务端 ID 与本地 ID 的后续补齐也会合并到去重账本。生成失败和发送结果未知均不会自动重试该消息。
- 微信被系统挂起、强退或未完成首次解锁时，不能保证自动回复。本功能不会自动开启后台保活；恢复后已过期任务不会补发。
- 后台音频保活仅提供执行机会，不能保证微信会主动收到免打扰群的普通消息。后台同步修复通过原生后台入口补充同步，忙碌时跳过，保留微信的登录、初始化和暂停保护；返回前台停止。30 秒是请求间隔，不是消息到达或回复完成的保证；真实延迟还取决于系统、网络、微信及模型服务。

## 连接与数据

请求采用 `Authorization: Bearer`、`model`、`messages`，仅支持 HTTPS 完整地址。通用接口 `stream:false`；百炼 `stream:true`，根据能力追加 `enable_search`、`search_options`、`enable_thinking`，SSE 只收集最终正文。客户端拒绝重定向，禁用 Cookie 与缓存，请求体最多 4 MiB、响应最多 1 MiB；JSON 编码与 Base64 校验在后台执行。图片不使用本地 file URL。未增加客户端工具循环、自动重试或新的后台定时任务。

每个微信账号的配置、去重账本和结果记录位于插件 `Library/Preferences/WeChatImprove/ai-reply-<账号 SHA256>.plist`，采用原子写入和文件保护。损坏文件保留并停止回复，不自动覆盖为默认配置。

API Key 保存在本机 Keychain，按账号与凭据版本隔离、不同步到其他设备；首次解锁后可在后台读取。新 Key 写入成功且配置保存成功后才启用；替换文件前保存失败会保留旧连接并清理新 Key。如果文件已替换、但目录同步失败，系统会保留前后两版 Key 并暂停使用配置；重新读取后无论落在哪一版，凭据都保持有效引用，新连接仍需重新测试。历史凭据版本仅保留在本机，供已有恢复事务精确回滚；停用当前 Key 会解除活动引用。配置导出不包含 Key 或凭据版本。

备份增加「AI 自动回复」模块，只导出预设、连接地址/模型、服务商与能力设置和会话规则（包括各群的免 @ 偏好），不导出 API Key、连接验证、去重账本、队列或结果记录。仅在备份原账号恢复，恢复后总开关关闭，需重新填写 Key 并测试连接。旧备份没有此模块时不会改写当前 AI 配置。事务回滚恢复原始本地状态。

## 开发与验证

2026-10-28 的性能清理移除了 AI 调用到的授权检查无效缓存及日志，减少了去重／历史提交的重复序列化和无须淘汰时的排序，提前过滤未启用的已知会话，并复用群消息解析规则。实时授权、持久去重和约 30 秒后台同步规则继续生效。性能排查、主机操作计数和真机测量边界见 [性能清理记录](../audits/ai-performance-cleanup-2026-10-28/README.md)。
