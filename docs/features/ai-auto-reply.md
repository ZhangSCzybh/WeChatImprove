# AI 自动回复

基于现有 Theos / Objective-C / Logos / UIKit 框架实现，使用插件设置样式和微信原生聊天详情分组。功能按微信账号隔离，总开关与每个会话开关默认关闭。

## 使用步骤

1. 打开「插件设置 → 功能增强 → AI 自动回复」。
2. 在「模型连接」填写兼容 Chat Completions 的完整 HTTPS 请求地址、API Key 和模型名称，点击「保存」。例如地址形态为 `https://服务域名/v1/chat/completions`，不会自动补齐路径。
3. 点击「测试连接」。测试使用固定短消息，确认返回非空文本；不发送微信消息，也不自动打开总开关。地址、模型或 Key 变化后必须重新测试。再次测试失败会撤销旧验证，取消测试保留已有验证。
4. 在「管理预设」新增、编辑或复制多个命名预设。提示词用于定义角色、语气和回复规则。选择全局默认预设；删除预设时选择替代项并更新会话引用，至少保留一个预设。
5. 开启总开关，进入某个聊天窗口右上角「…」的聊天详情，在「AI 回复」分组开启该会话，并选择「跟随全局默认」或独立预设。

设置页可查看已开启会话与最近 200 条回复记录。记录展示时间、会话、预设、结果和简短原因；不保存聊天正文、模型回复或 API Key。「已提交微信」只表示微信原生发送调用正常返回，不代表对方已收到。

## 回复规则

- 普通私聊仅处理符合条件的新文本消息。群聊必须在结构化 @ 名单中精确包含当前账号；手打 `@名字`、`@所有人`、仅有 @ 没有正文均不触发。
- 本人消息、历史消息、重复消息、系统消息、公众号/服务号和非文本消息不触发。
- 同一会话同一发送者的连续消息等待 2 秒后合并。同一会话串行处理，全局最多 2 个模型请求，最多等待 20 批；排队批次 120 秒过期，单次请求 60 秒超时。
- 模型上下文仅包含启用之后产生的内存对话，最近最多 10 条、正文总计最多 12000 个 UTF-16 单元；群按群与发送者分开。预设系统提示词另计。回复最多 4000 个 UTF-16 单元，不拆分发送。
- 关闭开关、修改配置、切换账号、隐私规则变化或人工回复，会取消尚未提交的任务。配置保存统一取消当前待回复任务并清空上下文。已经交给微信的消息无法通过关闭开关撤回。
- 首次启动、重新开启或清空运行状态后不补回复旧消息。由于微信时间戳精度为秒，开关变化所在那一秒的新消息可能被保守跳过。
- 已处理身份在本机持久化，服务端 ID 与本地 ID 的后续补齐也会合并到去重账本。生成失败和发送结果未知均不会自动重试该消息。
- 微信被系统挂起、强退或未完成首次解锁时，不能保证自动回复。本功能不会自动开启后台保活；恢复后已过期任务不会补发。

## 连接与数据

请求采用 `Authorization: Bearer`、`model`、`messages`、`stream:false`，仅支持 HTTPS 完整地址。客户端拒绝重定向，禁用 Cookie 与缓存，响应体上限 1 MiB。首版不包含图片、语音、工具调用或供应商专有协议。

每个微信账号的配置、去重账本和结果记录位于插件 `Library/Preferences/WeChatImprove/ai-reply-<账号 SHA256>.plist`，采用原子写入和文件保护。损坏文件保留并停止回复，不自动覆盖为默认配置。

API Key 保存在本机 Keychain，按账号与凭据版本隔离、不同步到其他设备；首次解锁后可在后台读取。新 Key 写入成功且配置保存成功后才启用；保存失败保留旧连接。历史凭据版本仅保留在本机，供已有恢复事务精确回滚；停用当前 Key 会解除活动引用。配置导出不包含 Key 或凭据版本。

备份增加「AI 自动回复」模块，只导出预设、连接地址/模型和会话规则，不导出 API Key、连接验证、去重账本、队列或结果记录。仅在备份原账号恢复，恢复后总开关关闭，需重新填写 Key 并测试连接。旧备份没有此模块时不会改写当前 AI 配置。事务回滚恢复原始本地状态。

所有自动化回归使用临时目录、URLProtocol 或原生替身，不调用真实模型、不读写主机真实 Keychain、不发送微信消息。已覆盖双重开关、预设继承、群聊真伪 @、身份补齐去重、合并与并发、人工接管、取消后迟到回包、凭据分阶段保存、旧账号/旧连接测试结果失效、配置损坏、未知发送不重试，以及备份去敏/暂停恢复/完整回滚。Theos 编译验证 `arm64` 与 `arm64e`。

仍需目标微信真机验收：原生聊天详情类与选择器是否匹配当前版本、实际页面排版与键盘操作、真实服务商响应、锁屏/后台调度及微信发送结果。构建通过和替身测试不代表这些真机流程已经验证。当前交付为开发分支，未安装或替换用户原环境。
