# 返回微信的清晰过渡 · 1.7-15

后续用户录屏仍显示返回时的亮度／清晰度突变，后续呈现方式调整见 [1.7-16](background-blur-snapshot-1.7-16.md)。下文保留本版本实现记录。

用户反馈返回微信时仍有一下跳动，并要求与进入切换器一样，用 0.22 秒逐渐清晰。

## 调整

- 两个方向共用 0.22 秒时长和 EaseInOut 曲线；正常返回从完整模糊平滑恢复清晰，完成后移除遮罩。中途往返继续反向衔接当前进度。
- 正常动画完成时沿用 UIKit 已到达的端点，去掉完成回调内再次设置 `effect` 的路径，避免在末帧重复更新模糊材质。反向完成也沿用 UIKit 恢复的起点。非正常中断或端点与最新目标不一致时，仍保留状态收束。
- 配置刷新只有在后台模糊开关确实变化时才即时应用；无关的 settings/local_settings_changed 通知不再截断清晰过渡。
- 完整后台模糊、关闭功能的立即清理、场景独立管理和系统减弱动态效果沿用原逻辑。

修改集中在 `Controllers/CSBackgroundBlurManager.m`。版本、内置更新说明及 README 同步为 1.7-15。
