# 列表圆角整理与绘制复用

2026-10-15，版本 1.5-14，基于本工作区 1.5-13 的实现做局部整理。目标是减少圆角重复设置，保护聊天分组、搜索、侧滑菜单及原有页面布局。

## 代码边界

- `Hooks/SessionGroupHooks.xm` 继续作为分组的原生接入层；原生索引作用域、搜索、会话更新、侧滑及删除确认边界保留。
- `Controllers/CSGroupListAdapter.m` 继续提供 `CSGroupCardPosition`，从当前显示分组确定首行和末行。
- `Hooks/ListCornerRadiusHooks.xm` 继续负责启用条件、背景视图、边距和原生页面布局。使用分组适配器的正式头文件，移除重复函数声明。
- `Controllers/CSListCornerRenderer.h/.m` 接收既有卡片背景、位置尺寸、圆角半径、首末行角色和颜色。聊天、通讯录、发现、我四处卡片绘制共用此函数，原有背景 tag 和路径工厂保持一致。

保留聊天列表和我的页面的 `cellForRowAtIndexPath`、`willDisplayCell` 两个有效入口，保证原生创建/复用后与实际显示前都有样式检查。未对整个 Cell 做按行号缓存或直接跳过整个样式流程；原生代码仍可能重建子视图或重置属性。

## 绘制复用

每个插件卡片背景通过关联对象持有一个遮罩和一份当前路径，随背景视图释放，无全局 Cell 缓存。

- 尺寸、圆角半径和首末行角色不变：复用遮罩与路径，不重新设置相同的 frame 和背景色。
- 仅位置或颜色变化：更新对应属性，复用原路径。
- 宽度、高度、半径、首末行角色变化：复用遮罩对象，更新路径；普通中间行不受圆角半径变化影响。
- 原生代码清空或替换遮罩、改写路径、圆角半径、裁剪状态、frame 或背景色：检查实际属性并恢复，不能仅根据上次输入判断无需更新。
- 复用遮罩更新路径时关闭这一小段操作的隐式动画，避免切组时圆角产生额外形变动画；调用方事务设置保留，frame 和颜色仍沿用 UIView 正常赋值行为。
- 分隔线 inset、layoutMargins、隐藏状态，以及 Cell/内容视图/子视图背景色，只有实际不同时才设置。原生子视图检查继续执行。

单行列表使用原来的全部圆角工厂；首行、末行使用原来的指定角工厂；中间行使用矩形工厂。没有替换圆角曲线算法，也没有引入离屏位图缓存。

## 清理依据

- 删除无调用者的 `adjustSubviewFrames` 静态递归函数。
- 删除通讯录中的空遍历、仅服务于调试日志的第三级视图遍历和未使用的 `labelRightEdge`。
- 删除发现页布局中的 17 处 `NSLog`，保留图标、标签、角标位置计算。
- 删除 8 个只有 `%orig` / 返回原 Cell 的圆角 Hook，以及空 `%ctor`。Logos 仍生成真实 Hook 的初始化入口。
- 删除分组适配器仅写入、从未读取的 `installing` 状态及其赋值。
- 合并四处重复的路径创建、遮罩安装和背景布局代码。

原生 Hook、代理回调、selector/反射入口不以“没有普通调用者”为删除依据。分组身份检查、账号隔离和兼容回退继续保留。用户预先存在的 `Headers/CSListCardGeometry.h` 不在本轮清理范围。

## 验证与性能边界

`bash Tests/verify-session-groups.sh --check-ios` 覆盖原有分组回归、分组圆角集成和新增渲染器检查，共 335 项：57 + 37 + 6 + 11 + 41 + 47 + 111 + 25。

渲染器测试运行实际生产函数与 macOS CALayer，UIBezierPath 使用记录调用参数的替身，不模拟 UIKit 圆角光栅化。检查包括初次创建、200 次相同样式调用无新增路径/遮罩、位置与主题变化、四种行角色、尺寸/半径变化、原生重置恢复、不同背景隔离、事务和释放。分组集成检查覆盖 A/B/C/D 过滤成 B/D 时的原生/显示索引、两个回调共用遮罩、切换单行与空分组、停用及其他列表。

完整 Release 包分别构建 rootless/rootful，并核验版本 1.5-14、安装目录、arm64/arm64e 架构；具体记录见 `artifacts/session-groups-corner-cleanup-2026-10-15/BUILD-INFO.json`。

本轮减少了重复路径/遮罩分配及属性写入。仍保留原有子视图检查、分组快照重建和 reloadData；没有宣称实现增量会话刷新，也没有实机帧率、耗电或内存下降的量化结论。

目标设备为微信 8.0.78 / iOS 27.0，尚未实机验收。需核对两项功能分别及同时启用、单行/首行/末行/中间行切换、长列表复用、置顶和删除、右侧 20% 会话菜单、左右边距、主题、大字体、横竖屏及通讯录/发现/我的页面。
