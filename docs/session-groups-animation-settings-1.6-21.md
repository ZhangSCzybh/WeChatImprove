# 1.6-21 分组动画开关与特效清理

在“聊天分组 → 其他设置”的颜色设置之后新增“分组指示器切换动画”。默认开启，沿用约 0.26 秒平滑移动、轻微伸展再收回的动画；关闭后，点击或手势切组时直接更新指示器与标签可见位置。系统“减弱动态效果”优先于插件开关。

配置使用独立的全局外观键 `com.wechat.enhance.chat_group.indicator_animation_enabled`，与颜色、字号设置保持一致。未设置或存储类型异常时默认开启，明确关闭可持久保存。设置沿用既有安全刷新通知；同一选中分组的刷新在关闭开关后也会停止未完成动画，开启时仍保留刷新不打断动画的行为。

删除原“滑动特效”开关、说明、旧键读取、会话行淡入和位移动画，以及只服务该效果的滚动状态。旧版本已保存的废弃键不再读取，无需迁移或清空用户偏好。分组切换手势、滑动灵敏度及原生会话 Cell 生命周期转发保持独立。

## 验证

- 指示器生产方法主机回放：23 项通过，包含默认值、关闭后保存、同一分组刷新取消、直接落位、重新开启、连续点击、布局刷新以及系统减弱动态效果。
- 原生表头语义回归：46 项通过。
- 列表视口回归：39 项通过。
- 测试偏好写入 UUID 独立 suite，结束时清理，不写用户真实设置。
- Rootless 包的架构、版本、构建产物一致性和废弃功能标记检查见同名 validation.json。

主机回放不能替代微信实机动画验收。本轮未在手机安装。建议安装后分别测试开启/关闭下点击标签和横滑切组，重启微信检查开关保存，再复查两条会话分组从通讯录返回的顶部位置。
