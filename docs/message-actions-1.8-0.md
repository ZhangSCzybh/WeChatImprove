## 行为与兼容约束

三个设置页面、现有默认值及存储键保持兼容，动作编号仍为禁用0、引用1、删除2、转发3、收藏4、撤回5、复读6。手势复读独立于菜单复读和语音转发开关。统一上下文、能力检查和每目标提交状态；只有手势 Ended 能提交；取消/Failed/重用/账号变化不允许旧上下文发送。提交结果未知时不调用另一发送路径。源消息、源媒体只读，每个收件人拥有独立消息身份。

转发保持微信原生选择、确认、留言、取消和清理，绑定精确的操作和收件人。媒体在后台串行准备，回调不同步读取插件媒体；语音长度与时长分别处理，完整性和元数据重新验证后才可提交。页面和单元格短操作可取消，已提交操作按其自身生命周期收束。滑动、时间、合并布局统一调度，保留原生变换及系统减弱动态效果。
