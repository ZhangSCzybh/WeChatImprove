# 原生悬浮底栏重构 · 1.6-36

本版本完成代码重构、主机测试和 Rootless 双架构打包。没有连接手机、安装插件或重启微信；真实微信交互与视觉效果尚待实机验收。

## 功能与配置

- 保留四入口普通/选中图标、隐藏文字、自定义文本、胶囊/圆角、背景颜色/透明度、描边、触感与描边动画。
- 宽度保留 0.6/0.7/0.8/0.9 档位，保证每个入口至少 44 pt 的矩形布局宽度（宿主宽度足够时）。
- 新增独立内容高度 44–80 pt，默认 52 pt；上移范围 0–100 pt；底部安全区不参与内容缩放。
- 新增描边宽度 0–6 pt，默认 1 pt，0 为关闭。未配置描边颜色时不绘制。
- 未设置背景时使用原生宿主背景色和系统材质；可以自定义颜色与透明度，也可以切回跟随原生。
- 明确区分未配置颜色和显式透明黑。恢复默认会清理高度、描边宽度、触感、动画和描边颜色。
- 使用原生 item 在主底栏 items 中的位置映射配置；不匹配中英文标题、不写入原生 index。
- 沿用旧偏好键和图片路径；旧负偏移按 0 处理。旧大小档位改为控制宽度，高度独立。
- 图片导入保留颜色、比例和透明度，不强制方形裁剪、不自动抠除白色；原子替换文件失败时保留旧图标。

## 实现与清理

`Hooks/TabBarStyleHooks.xm` 只负责把原生生命周期转发给适配器，始终调用原生实现。`CSTabBarNativeAdapter` 按主底栏实例保存和恢复状态；`CSTabBarPreferences` 统一默认值、范围和图片缓存；`CSTabBarGeometry.h` 提供可独立验证的几何计算。

原生 MMTabBar 宿主 frame、项目视图父子关系、按钮 target/action、手势和角标对象保持归微信管理。插件在宿主内绘制悬浮背景，将原生项目和按钮置于统一矩形，扩展宿主命中测试到上移区域，区域外允许穿透。角标只移动位置，不修改数字、字符串、形状或隐藏状态。主列表单击、双击和长按路径继续保留。

原生布局执行前归还本插件修改的项目和按钮 frame，布局后再应用悬浮布局。图片、文字和角标布局事件使用嵌套保护。阴影动画和背景路径仅在配置、尺寸或主题改变时更新，不在每轮布局中重启动画。触感监听附加于原生按钮，等原生回调完成并确认选中项变化后触发。

当前根页面主表按实际遮挡增加必要的 contentInset.bottom 和竖向滚动指示器余量。只管理底部数值，不修改顶部、左右或 contentOffset；切页、隐藏或关闭后释放。其他代码已经替换的底部值不会被旧快照覆盖。内容保持微信原有布局，可在滚动时经过悬浮区域下方；没有强制扩大所有页面的内容 frame 到屏幕底部。

已删除：CSCustomTabBar、自建导航 UIButton、角标复制与 0.5 秒定时轮询、中文标题匹配/覆盖 index、四页面类名白名单、强制隐藏原生底栏、无条件重建按钮与动画、错误签名的 Darwin 回调、重复默认值及不再使用的枚举、自动抠除图片白色的处理函数。

仅适配 MainTabBarViewController 所属的四项目底栏。原生控制不可用、结构不支持、有宿主遮罩或裁剪祖先阻挡悬浮区域时恢复原生显示，避免显示不可点击的导航。没有劫持其他业务页面的 TabBar。

## 实机验收

1. 安装与设备注入环境一致的 1.6-36 Rootless 包，进入底栏样式开启；核对插件显示版本。
2. 四入口逐一点击，检查选中状态、点击边缘、主列表重复点击/双击与长按是否仍为原生行为。
3. 分别接收未读数字和小红点，测试数字增加、清除、从短数字变长，以及发现/我页面提示。
4. 连续调整宽度、高度、上移、圆角、背景透明度、描边与隐藏文字；确认角标跟随图标、背景外可滚动、末行可完整显示。
5. 设置普通/选中图片并清除，检查白色图案、透明图案和非方形图片；重命名标签后再验证图标映射。
6. 进入聊天、搜索、二级页面及返回，包含取消侧滑返回；切换深浅色与横竖屏，检查恢复和热区。
7. 开关悬浮栏并返回原生模式，确认文字、图标、底部滚动空间和显示状态恢复。结合聊天分组、列表圆角和全局缩放检查。

本轮没有访问真实微信账号、配置或数据库。主机替身测试不能证明 UIKit 实际渲染、所有微信版本或其他插件组合均兼容。
