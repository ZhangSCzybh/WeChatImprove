# 聊天功能调试代码清理（1.6-24）

用户已在微信 8.0.78.34 / iOS 27.0.1 / Rootless 确认 1.6-23 的消息时间位置正常。本次按要求清理消息合并、气泡样式、消息时间三个功能的运行时调试代码。

## 清理范围

- 消息合并：移除间距应用/保护日志、行高与内容尺寸日志、布局回退日志、仅用于诊断的子视图枚举，以及三个专用几何记录 API。
- 气泡样式：移除应用/失败/配置变化日志和日志专用的 `lastFailure` 字段。
- 消息时间：移除显示状态日志、日志去重关联对象以及颜色归档/解档的控制台输出。
- 测试：删除已移除日志内容的断言与气泡日志替身，保留功能回归、原生行高回退和通用诊断缓冲区测试。时间测试不再链接诊断实现。

保留合并布局越界保护、紧密间距计算、原生背景恢复、气泡缓存、时间坐标转换及标签复用。版本控制里的通用诊断入口继续用于防撤回；开启诊断后，这三个功能不再写入记录。未改动设备上的诊断开关或其他设置。

## 验证

- 时间生产代码生命周期：138 项断言通过。
- 消息合并/导航策略：53,201 项断言通过。
- 原生适配/导航生命周期：2,881 项断言通过；较上一版减少的 11 项是被删除的合并日志内容断言，保留对应布局行为断言。
- 气泡策略/渲染/所有权：8,269 项断言通过；气泡适配生命周期：111 项断言通过。

测试使用主机 UIKit 替身，不代表本版已安装到真机。Rootless 构建与二进制清理校验见 [验证记录](chat-debug-cleanup-1.6-24-validation.txt)。安装包为 `packages/com.wechat.improve_1.6-24_iphoneos-arm64.deb`。

清理减少了诊断字符串构造、状态记录和诊断专用视图遍历；没有进行设备耗电测量。未修改账号、聊天数据库或安装环境。
