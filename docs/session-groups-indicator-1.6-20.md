# 1.6-20：日志清理与分组指示器动画

用户已实机确认 1.6-19 的顶部空白问题解决，并要求清理排查日志、增加分组切换动画。用户已确认约 0.26 秒滑动、轻微伸展后收回、不反弹的方案。

## 清理范围

删除分组适配器的 `recordViewport:` 方法与声明、appear/refresh/reload/restore 阶段调用、仅用于这些日志的 `CSChatDiagnostics` 引用。删除诊断专用的 `CSGroupNativeTopAreaState` 及四个私有布尔字段的 runtime 探测，不再为了日志直接读取 UIScrollView 的底层 inset。

保留 MainFrameTableView 的原生搜索表头识别、独立表头读取作用域、短列表锚点保护，以及已有通用兼容性诊断和“清空”按钮。历史调查文档与回归证据保留，方便追溯。本次没有清空用户数据，也不关闭用户的诊断开关。

## 动画与刷新问题

原代码在点击时请求 0.18 秒 UIView 动画，但适配器立即发布分组投影，重复设置 `selectedTabID` 时又以 `animated:NO` 选择同一项，执行 removeAllAnimations，导致动画被同步取消。

现在相同选中项的重复设置不会取消正在执行的动画。逻辑选中项仍立即更新，不等待动画完成。位置和宽度使用原生 Core Animation 关键帧：

- 总时长 0.26 秒，指示器向目标移动，途中轻微伸展，最终匹配目标文字对应宽度；额外伸展量取移动距离的 12%，最多 14 pt。
- 点击和现有左右滑动切换都走统一选择入口。
- 快速连续切换从 presentation layer 当前可见位置接续，替换同一个动画 key，不排队、不依赖过时的 completion 回调。
- 普通刷新和相同目标布局保留当前动画；未读角标或文字布局导致目标改变时重新对齐。
- 分组栏横向定位同步平滑移动；相同横向目标不重复写入偏移。
- 首次显示、离开 window、无有效分组、容器尺寸改变时直接定位或清理动画。开启系统“减少动态效果”后不执行指示器滑动，并监听该设置变化。
- 动画只控制分组栏内部视图和其横向滚动，不设置主会话列表 inset、offset、表头高度或系统安全区。

显式链接 QuartzCore，原有选中颜色、指示器颜色、字号、宽度规则与触感设置继续使用。
