防撤回拦截、气泡配色/圆角、隐藏头像偏好仍各自受独立开关控制。尚未通过真实微信验证多个 Hook 调用链及各功能组合。关闭消息合并只能退出合并覆盖，不能撤销本次对气泡、时间和头像代码的更新；整体回退需安装保留的旧包。

## 实际实现

原实现按时间搜索消息、猜测前台控制器，并在表格行高上单独减去间距。新实现保留微信原生节点和 Cell，由真实聊天控制器、表格、section/row 直接绑定当前模型。

| 文件 | 职责 |
| --- | --- |
| `Controllers/CSMessageMergePolicy.h/.m` | 配置快照、相邻归组、安全间距、严格链接解析、导航坐标纯函数 |
| `Controllers/CSMessageMergeAdapter.h/.m` | 每个聊天的弱引用上下文、模型状态、复用恢复、原生测量适配、可见行差量刷新 |
| `Hooks/MessageMergeHooks.xm` | 原生生命周期、行绑定、增删替换事务、测量及布局的入口 |
| `Controllers/CSMessageNavigation.h/.m` | 原文查询、身份验证、原生加载/高亮和实际可视范围纠偏 |
| `Controllers/CSMessageTimeLayout.h/.m` | 时间标签布局与点击显示条件，可独立回归 |
| `Hooks/RevokeHooks.xm` | 撤回提示的会话归属、富文本转义与两个点击入口 |
| `Hooks/AvatarHooks.xm`、`Hooks/MessageTimeHooks.xm`、`Hooks/BubbleStyleHooks.xm` | 配套头像偏好、时间标签及有界气泡缓存 |

归组只判断真实相邻消息，要求账号、会话、发送者、方向一致，消息身份有效且类型受支持。群聊必须取得真实发言人；没有可靠身份时不归组。时间戳不参与定位，同秒大量消息不再受原有搜索窗口限制。模型状态与所属聊天绑定，页面退出不保留控制器强引用。

现有配置键、头像首尾选项和已保存间距保持兼容。没有保存值时仍默认全会话范围、尾部头像、间距 4 pt；零间距有效，读取设置页不会写入默认值。系统消息及未知消息类型形成归组边界。

## 群聊、私聊与间距

头像通过视图隐藏保留原生水平布局。群聊另处理昵称、描述和文本状态视图，单行模型通过原生昵称可见性入口参与测量，不再使用“群聊间距乘二”。布局前恢复本模块拥有的隐藏覆盖，布局后重新应用；复用、关闭功能和变更范围都经过相同恢复过程。原生已隐藏的元素不会被强制显示，不改原生 alpha 或 transform。

行高以原生 `measure:` 结果为唯一调整入口，不再在 `heightForRowAtIndexPath:` 另减一次。正间距受配置范围限制；负间距仅压缩已观察到的安全底部留白，并为可见子视图保留 2 pt 余量。文字、图片、语音、视频、表情的精确模型类进入适配范围；内容/尺寸/签名不符合预期时退回原生。

运行时校验测量结果是否真正到达表格行高。若微信的内部缓存绕过测量返回值，则停止本代间距调整，避免模型尺寸与表格尺寸竞争。发现子视图重叠时也取消压缩，直到内容或布局版本更新。

**明确回退范围：**长文本拆分为多行时，仍可按逻辑消息归组头像，但保留原生高度及昵称测量；未知类型、动态结构无法确认、后台缺少有效上下文、无法确认留白时不做负间距压缩。因此设置为 -20 pt 不代表每条消息都减少 20 pt，也不承诺每种业务卡片具有完全相同的间距。

## 刷新和能耗设计

- 消息变化只重算可见行及其相邻关系。追加消息没有改变当前可见消息决策时，不额外触发整段可见内容重测或表格高度事务。
- 刷新请求在主线程合并；拖动、减速、菜单、编辑和原生未提交更新期间延后。滚动结束、菜单真正关闭及加载完成等事件恢复待办，不进行周期轮询。
- 几何修正按内容版本记录，原生不接受结果时停止重试；没有 Timer、CADisplayLink 或静止时主动刷新循环。
- 自身调整高度时保存当前可见消息身份和行内偏移；不会因为普通消息变动强制拉回底部。原文导航进行中由导航管理滚动位置。
- 气泡图片使用 NSCache，限制 128 项、8 MiB 成本，在相关样式变化和内存警告时清理；移除原合并滚动路径的同步队列和高频日志。
- 消息时间在主线程绑定，不再让后台任务持有将被复用的 Cell；复用 NSDateFormatter，当前显示的 Cell 为弱引用。头像隐藏时，时间位置使用实际气泡/内容视图。原有时间样式更新仍有格式、颜色和文本尺寸处理，并未宣称全部热路径零分配。

这些是减少额外工作的机制与测试结果，**并非已测得的帧率或省电比例**。其他插件动画、微信原生绘制和设备热状态仍会影响表现。

## 防撤回原文定位

撤回提示插入命中原文的实际会话，展示文本经过富文本转义。点击入口分别接入头文件声明的 `BaseMsgContentLogicController.onClickMsg:` 和系统消息链接回调，复用统一导航实现。

只接受完整的 `revoke_jump_` 十进制正整数 ID。查询前后校验当前账号、当前会话、提示所属会话、返回消息的服务器 ID 与会话关系，不依赖 Cell 或旧 indexPath。查不到原文或接口不兼容时给出失败提示。

先调用原生 `scrollToMessage:highlight:marginTop:animated:` 完成历史加载和高亮，使用实际表格可视高度、adjustedContentInset 与输入工具遮挡计算位置。删除固定屏幕高度、固定导航栏/输入框高度及将绝对 offset 再作为 margin 的旧逻辑。待目标节点就绪，先处理合并布局再按最新节点位置进行最多一次纠偏；超长消息顶部对齐。拖动或离开页面取消待办，无定时器重试。

尚需实机确认原生异步加载回调顺序、搜索/未读定位与其他插件动画的组合。缺少完成回调且目标未加载的请求保留到后续原生事件或拖动/离开页面取消，不会后台轮询。不同微信版本的私有接口能力不可仅凭头文件保证。
