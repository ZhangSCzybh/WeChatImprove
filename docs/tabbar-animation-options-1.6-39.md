# 1.6-39：扩散与经典描边动画可选

在底栏样式的“描边动画”中同时提供：

| 选项 | 保存值 | 效果 |
| --- | --- | --- |
| 无动画 | 0 | 仅保留静态描边 |
| 扩散呼吸 | 1 | 1.6-38 的空心轮廓缓慢向外扩散并淡出，3 秒一轮 |
| 扩散心跳 | 2 | 1.6-38 的双次向外扩散，1.2 秒一轮 |
| 经典呼吸 | 3 | 恢复 1.6-37 的整条底栏阴影明暗变化，3 秒一轮 |
| 经典心跳 | 4 | 恢复 1.6-37 的整条底栏双峰阴影变化，1.2 秒一轮 |

保存值 1/2 沿用 1.6-38 的含义，升级不会把当前扩散动画切换为经典动画。经典模式沿用旧版 6 pt 阴影半径和原透明度关键帧；扩散模式继续排除底栏内部的光晕。设置读取范围同步扩展到 0–4。

刷新样式时先移除两类动画，清空背景阴影并隐藏外扩图层，再启用所选模式。无动画、零描边宽度和系统减少动态效果均停止动画；关闭底栏功能也会清理两类动画。实栏和转场快照共用同一渲染方法。

验证：`bash Tests/verify-tabbar.sh` 通过，覆盖已有几何、生命周期、快照和外扩遮罩测试，并验证新选项值读取、经典模式的原关键帧/时长、扩散与经典互切和关闭动画后的清理。主机使用 UIKit 替身并记录提交给 QuartzCore 的动画副本，不能代表手机动画观感。

Rootless 构建：`make package -j4 SCHEME=rootless PACKAGE_VERSION=1.6-39`，包含 arm64 / arm64e。包与校验结果见 [validation.json](tabbar-animation-options-1.6-39-validation.json)。未连接手机，未操作微信配置或数据。
