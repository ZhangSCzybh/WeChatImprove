# 后台模糊过渡优化 · 1.7-14

后续反馈：用户要求返回也使用 0.22 秒逐渐清晰，并反馈返回时仍有一下跳动。后续调整见 [1.7-15](background-blur-return-1.7-15.md)。下文保留本版本实现记录。

用户确认 1.7-13 基础功能正常，但进入／退出模糊时的变化过于生硬。原实现直接添加完整模糊，并在恢复活跃时立即删除视图，缺少过渡。

## 调整

- 失活时同步添加空效果视图，用 `UIViewPropertyAnimator` 在约 0.22 秒内将 `effect` 从 nil 过渡至原有 `UIBlurEffectStyleRegular`。
- 恢复活跃后约 0.24 秒渐退至 nil，完成后才移除视图。动画期间仍不接收触摸，不阻塞操作。
- 使用系统 EaseInOut 曲线，模糊视图的 alpha 始终为 1。保留完整模糊时的强度与色彩表现。
- 往返发生在动画中途时，反转原 animator，沿当前进度继续。重复通知不重启动画。
- 应用或相应场景进入后台时停止未完成动画，立即落到完整模糊状态，避免动画因挂起停在中间状态。此时进入动画可能短于 0.22 秒。
- 停止的动画失去所有权；完成回调必须匹配当前窗口、遮罩及 animator，旧回调不能清掉新遮罩。
- 关闭功能、重置／导入配置、窗口隐藏或移除、场景断开时立即清理。系统启用“减弱动态效果”时直接切换；运行中开启该设置会收束当前动画。

主要实现仍在 `Controllers/CSBackgroundBlurManager.m`。配置键、入口和默认开关不变，升级沿用现有设置。版本号及内置说明更新为 1.7-14。
