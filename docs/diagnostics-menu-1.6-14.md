# 1.6-14：诊断入口迁移

用户确认 1.6-13 的首条消息间距修复可用，本次按要求将问题排查功能移到版本控制菜单。

入口：插件设置 → 版本控制 → 页面底部“问题排查（不记录聊天内容）”。包含兼容性诊断开关、查看诊断记录、复制诊断记录。防止撤回页面移除该分组。

将原有诊断 UI、报告格式化、复制提示和报告详情页移入 CSVersionSettingsViewController.m；版本页 didSelectRowAtIndexPath 优先分发 actionBlock。新分组追加为第 4 组，既有预设版本、自定义版本及说明的索引不变，展开自定义版本时仅替换第 2 组，诊断分组仍保留。诊断开关继续使用 CSChatDiagnosticsEnabledKey，无设置迁移，不发版本切换通知，不触发重启提示。

保留查看页的导航返回、无导航容器时的关闭按钮、可选择文本以及复制成功提示。聊天间距、气泡、防撤回、消息时间与诊断采集实现未修改。

本次为设置入口搬迁，采用源码路径审查与完整 Rootless arm64/arm64e 编译、安装包元数据及动态库校验；未为 UI 搬迁增加模拟测试，未重复运行聊天核心回归。没有连接设备验证实际点击，未安装包、修改数据库或设备设置。详细构建记录见 diagnostics-menu-1.6-14-validation.txt，旧包保留。
