# 1.6-38：描边向外扩散

旧实现将 shadowPath 设置为整个底栏的实心圆角矩形，并在底栏背景图层上动画修改 shadowOpacity。透明背景下阴影也覆盖底栏内部，看起来整条底栏都被描边颜色染色。

现在保留静态描边，另用独立 CAShapeLayer 绘制无填充的轮廓。轮廓从描边开始向外扩展 10 pt，模糊半径从 0 增至 8 pt，并逐渐淡出。环形图层的阴影由线条自身生成，不再提供实心 shadowPath；底栏背景图层不再设置阴影或动画。

光晕容器四周留出 36 pt 绘制空间，使用 even-odd 路径遮罩挖去整个底栏内部。圆角、胶囊及透明背景都遵守同一边界，光晕只显示在外侧。底栏贴屏幕底边时，屏幕以外的扩散自然不可见。

- 呼吸：3 秒单次外扩、渐隐。
- 心跳：1.2 秒双次外扩，两次之间在透明状态复位。
- 无动画、描边宽度为 0 或开启系统减少动态效果：隐藏光晕，移除动画。
- 禁用底栏时清理外扩动画。原生转场快照使用相同的背景渲染方法。

高度、宽度、偏移、图标、文字、原生角标及导航交互沿用 1.6-37。

验证：`bash Tests/verify-tabbar.sh` 通过，包含既有几何、生命周期、原生恢复及快照测试，并新增透明背景不带整块阴影、内部被遮罩排除、外部可见、轮廓宽高各增加 20 pt、两种节奏的时长、透明起止和关闭动画清理断言。主机无真实窗口时 QuartzCore 会在提交事务后丢弃动画，因此测试记录提交给 QuartzCore 的动画副本；路径和遮罩仍使用真实 CoreGraphics/QuartzCore 对象。这不是手机渲染验证。

Rootless 包构建包含 arm64 / arm64e；校验记录见 [validation.json](tabbar-border-1.6-38-validation.json)。未连接手机，未读取或修改微信数据。实机重点检查透明背景下中心无染色、四周向外扩散、呼吸/心跳切换、关闭动画后无残留，以及返回列表转场中的相同外观。
