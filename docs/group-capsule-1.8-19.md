# 1.8-19 聊天分组胶囊包裹

2026-10-18。在用户原有 `WeChatImprove` checkout 中开发，基于现有 1.8-18 工作区，保留此前语音、支付和分组修复，以及本会话已完成的六项设置图标更新。

## 设置与兼容

入口：插件设置 → 界面定制 → 聊天分组 → 其他设置 → 分组指示器切换动画。

| 选项 | 行为 |
| --- | --- |
| 下划线 | 保留原有 0.20 秒平移与伸展；拖动时横线收窄，松手后恢复正常宽度。 |
| 胶囊包裹 | 标题背后的圆角色块原地收拢、展开，文字交叉淡入淡出，0.28 秒完成。文字与红点不缩放、不位移。 |
| 关闭 | 沿用旧开关关闭时的行为：保留下划线，立即落位。 |

升级不自动启用胶囊。未保存新选项时，按旧 `indicator_animation_enabled` 开关决定下划线或关闭。新键为 `com.wechat.enhance.chat_group.selection_indicator_style`；不读取已回退旧版本曾使用的 `indicator_animation_style`，避免将其他旧动画编号解释成胶囊。读取不写入配置；显式选择时同步旧布尔开关，保留降级兼容。异常值回退旧偏好。

胶囊沿用现有颜色配置：`indicator_color` / `indicator_color_dark` 生成底色，保留原颜色 alpha 后分别乘以 0.16 / 0.24，得到浅色填充；`selected_text_color` / `selected_text_color_dark` 原样控制选中标题。颜色选择器和既有颜色档案不变。

## 实现边界与性能

- 业务分组、账号归属、成员筛选、排序、未读计数、搜索及原生列表投影未改动。
- 分组按钮宽度、标题位置、红点布局、52 pt 基础栏高和字号规则沿用原实现。胶囊只根据现有标题区域布局，零尺寸及无交集布局返回安全空矩形。
- 胶囊模式按需创建一个背景 CALayer 和一个不接收触摸、不重复参与无障碍的标题 UILabel；复用这些对象，离开胶囊模式时移除并释放。
- 使用有限时长的 Core Animation `opacity` / `transform` 动画，没有新增 timer、display link、常驻刷新、阴影或模糊。普通相同目标刷新不会重新添加动画。
- 快速切换从 presentation layer 的可见状态衔接；拖动直接更新图层，不逐帧排队动画，不提前提交分组或触发触感；松手提交和取消复用原有选择路径。
- 首次显示、非动画设置同步、离开窗口和系统减弱动态效果直接落位；系统关闭动画时清理正在运行的胶囊动画。
