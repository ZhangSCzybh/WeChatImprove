## 实现与存储

`CSCloseFriendEntryState` 只管理非认证性质的发现偏好，以及与既有入口隐藏选项的组合判断。使用独立的 `NSUserDefaults` suite `com.wechatimprove.closefriends.entry-discovery`，键为 `discovered.v1.<账号 SHA-256>`，值为布尔值。首次成功写入同步持久化后才反馈；写入失败恢复原值。现有有效凭据直接满足已发现条件，不需要改写或迁移密友密文。

`CSCloseFriendManager` 提供入口查询、触摸开始令牌和发现操作；沿用账号 epoch 锁与运行时 token 校验。头像手势和列表刷新在 `CSCustomViewController` 中实现，兼容原生设置容器。`presentSettingsFrom:` 同样检查入口，拒绝尚未发现或已隐藏的失效路由。

密友名单仍在微信容器内 `Library/Preferences/WeChatImprove/CloseFriends/`，认证与加密凭据仍由原钥匙串服务管理。发现偏好不是密友密码，不进入普通插件配置备份或重置登记。没有迁移或访问真实账号数据。
