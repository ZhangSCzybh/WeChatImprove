# 1.8-13 分组指示器动画可选

在原有 WeChatImprove checkout 中完成。用户已确认保留现有效果，并加入预览中的三种新动画；“分组指示器切换动画”由开关改为原生选择菜单，当前效果显示在设置行右侧。版本更新为 1.8-13。

## 设置与表现

路径：插件设置 → 聊天分组 → 分组指示器切换动画。

| 选项 | 表现 | 点击时长 |
| --- | --- | --- |
| 经典收缩 | 保留原有点击伸缩；滑动时在目标标题下方缩至最短，再原地展开 | 0.20 秒 |
| 流体牵引 | 前端先向目标延伸，尾端随后跟进，恢复正常宽度 | 0.36 秒 |
| 轻弹滑行 | 平滑滑向目标，轻微越过后回落，途中小幅伸展 | 0.32 秒 |
| 微弧跃迁 | 沿小弧线抬起，收窄后落回目标标题下方 | 0.36 秒 |
| 关闭 | 选中分组后直接落位，不显示拖动预览 | 无 |

三种新效果的点击与手势几何共用同一个函数。拖动时跟随进度，反向拖动沿原路径返回；松手提交或取消时使用 0.20 秒直接收尾，不重新播放牵引、回弹或跃迁。原有切换阈值、方向判断与触感提交条件保持原实现。

旧配置只读兼容：原开关开启或未配置时使用经典收缩，关闭时保持关闭。新样式有效时优先采用新值；类型、范围或整数校验失败时回退到旧开关。用户选择时同时保存样式与兼容旧版本的开关值。读取配置不会写入默认值。

快速点击切换从当前 presentation layer 的位置和尺寸继续；普通布局、角标刷新及相同选中项的回写不重播动画。切换样式时清除旧样式的过渡或拖动预览。关闭动画、开启系统“减弱动态效果”或视图离开 window 时直接落位。

## 实现与性能

- `CSGroupAppearance.h`：样式枚举、配置读取、旧开关兼容、名称映射与保存。
- `CSGroupIndicatorMotion.h`：共享几何与有限时长，保留经典手势的目标位置收缩逻辑。
- `CSChatGroupSettingsViewController.m`：五个选择项、当前项标记、取消及 iPad 弹出菜单定位，保存后通过既有通知刷新。
- `WESessionTabContainerView.m`：样式切换与动画播放，继续使用 Core Animation。

新动画每次点击最多采样 25 个位置和尺寸关键帧，然后交给 Core Animation 播放一次；手势更新只计算当前进度的几何。没有新增常驻计时器、显示刷新回调、无限动画、后台轮询或诊断日志。新效果比经典动画多了有限的一次性采样和最多 0.16 秒播放时间，不能据此承诺 CPU 或温度改善；静止时没有新增动画任务。
