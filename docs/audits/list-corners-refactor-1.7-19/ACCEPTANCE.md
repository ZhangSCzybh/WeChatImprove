# 1.7-19 列表圆角实机验收

基线：1.7-17；新包为 Rootless、arm64 + arm64e。代码来自独立 `codex/list-corners-refactor-1.7-17` 分支。以下项目是待用户实机执行的验收，不表示已通过。

## 安装与启动

- 确认插件设置的版本信息显示 1.7-19；保留已有配置，不重置微信或聊天记录。
- 完全退出微信后冷启动，确认能进入会话列表；重复启动及前后台切换。
- 分别验证四种组合：圆角关/分组关、圆角开/分组关、圆角关/分组开、圆角开/分组开。仍按设置页提示重启使完整布局生效。
- 若出现启动失败，保留本次 crash 日志和实际安装版本，不把主机测试通过当作启动通过。

## 会话与分组

- 单行四角、首行上角、末行下角、中间直边正确；左右边距、置顶顶部距离及普通会话距离与 1.7-17 一致。
- 头像、昵称、时间、未读、消息摘要、状态、免打扰及现有横幅没有缺失或被裁剪。
- 空组、单行组、多个自定义组切换；收到新消息、置顶/取消置顶、删除后边界更新正确。
- 在过滤后的组中点击和删除会话，确认操作的是对应会话；不能只检查行号或卡片外观。
- 打开侧滑菜单并切组、取消侧滑、长列表复用，菜单、卡片和内容一起移动，没有背景留在原位或文字累积偏移。
- 原生搜索和分组快捷搜索进入/退出后，分组、标题、搜索栏、顶部位置保持正确。
- 下拉微信原生顶部区域、跨页面返回、进入聊天再返回，列表没有新增顶部空白或滚动跳动。

## 通讯录

- 顶部合并卡片与后续字母分组的首末圆角正确，图标、昵称、箭头没有错位。
- 点击字母索引仍定位正确；联系人数量、搜索和原生入口不受影响。
- 企业/OpenIM 描述、长昵称、状态、右侧按钮、多行/展开描述保留。
- 滚动复用后分割线和背景没有重现，位置不会反复增加边距。

## 发现

- 每组入口的首末圆角正确；标题、左图标、右箭头、头像提示、角标、红点和富文本保留。

## 我

- 个人资料卡片头像、昵称、微信号、二维码和状态按钮均显示、可点击。
- 状态卡片展开/收起、长昵称、大字体下没有裁切或覆盖。
- 隐藏/恢复功能入口、显示自定义插件入口后，列表首末圆角正确，入口不重复或消失。
- 收藏验证及原生功能跳转保持有效。

## 配置与绘制

- 圆角半径 5–30，左右边距各 1–30，两个会话距离各 0–50；左右不对称设置保持有效。

- 恢复默认保持 1.7-17 原有语义；不会关闭总开关或清除未由原重置操作处理的距离背景色。
- 宽度变化、快速切换四页与持续滚动后没有新遮罩堆积、内容漂移或明显卡顿。
