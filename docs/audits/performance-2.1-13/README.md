日期：2026-10-29。在原项目工作目录 `/Users/zhangshichao/Documents/Workspace/WeChatImprove` 更新版本并打包。安装包版本、插件显示版本、内置更新说明及 README 已同步为 `2.1-13`。

## 本版变化

1. **AI 存储异步化。** 配置、消息去重和历史写入使用后台串行 I/O 队列，主线程读取已发布快照。配置保存成功后再结束页面操作，消息去重保留文件及目录持久化检查。历史展示记录按约 1 秒或累计 10 条合并写入。
2. **AI 上下文缓存限额。** 常驻缓存最多 32 组“会话＋发送者”，文本总预算 256 × 1024 个 UTF-16 单元，闲置 30 分钟后清理，超限优先释放最久未使用的缓存。单组仍限制 10 条消息／12,000 个 UTF-16 单元；内存警告清理缓存，正在处理的回复继续执行。
3. **普通角标刷新合并。** 连续事件按 80 毫秒合并，持续突发时最长 250 毫秒触发一次。隐私策略、账号及原生恢复等变化继续及时刷新，沿用会话隐藏过滤与稳定快照保护。
4. **自动备份按需调度。** 设置变化按 300 毫秒合并，持续变化最多等待 2 秒计算摘要；按最近截止时间设置单次唤醒，无任务时停止计时。关闭自动备份或进入后台时暂停摘要计算，恢复前台后补齐核对。保留 30 秒静默、5 分钟持续修改检查及失败重试规则。

本版同时修复两处联动边界：已接收的消息 ID 别名在切号后仍写入原账号，旧回调不能继续发送；备份预览及准备恢复前先在后台排空待写 AI 历史，避免延迟写入使恢复计划失效。账号身份校验、过期回调拦截及恢复 revision 一致性校验继续有效。

继续包含 `2.1-12` 的设置分组调整及 `2.1-11` 的密友消息静默移除与旧配置兼容。支付摘要、来电保护和未读面板仍在使用的接口保留。

## 构建与产物

[build-packages.py](build-packages.py) 为 Rootless、Rootful 分别创建全新临时构建目录，并行执行 `make package -j4`，指定 `PACKAGE_VERSION=2.1-13`。沿用现有 Theos／Xcode 环境，不执行 `make clean`。

- Rootless：退出码 0，耗时 21.047 秒，6 条既有警告。
- Rootful：退出码 0，耗时 21.040 秒，6 条既有警告。

两包均包含 arm64、arm64e，最低目标 iOS 15.0。每种方案的 6 条警告与上一版一致：`UILocalNotification` 弃用两条、`statusBarFrame` 弃用两条、链接参数 `-multiply_defined` 过时两条。

[verify-packages.py](verify-packages.py) 校验包版本及架构、安装前缀、注入过滤 plist、包内与 staging 动态库哈希、支付／来电／未读面板保留符号，以及退役静默符号缺失。两种方案的四份 dSYM UUID 均匹配对应二进制，调试符号 ZIP 共 12 个文件，CRC 通过。最终独立执行 `shasum -a 256 -c SHA256SUMS`，两个安装包及调试符号全部通过。

生产输入哈希前后一致；构建前已有的 `.theos` 与 `packages` 共 1,288 个文件全部保留，无缺失或哈希变化。详见 [构建结果](build-result.json)、[包校验](package-verification.json) 与 [既有产物保留核验](preserved-artifacts-after.json)。
