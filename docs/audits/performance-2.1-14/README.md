## 本版变化

1. **折叠摘要按需生成。** 先按分组、隐私和原生排序选出候选，只格式化最终可见的一条；每次刷新继续读取原生名称与正文。
2. **消息手势按需创建。** 关闭时跳过适配器、pan 和气泡几何处理；重新开启后恢复可见 cell，公共消息时间及连续消息合并继续工作。
3. **合并圆角重复布局。** 同一次原生表格布局中的子 cell 几何修复合并到表格布局结束；保留独立 cell、前台恢复、主题变化、内容容器替换及最终折叠入口保护。
4. **AI 消息提前过滤。** 禁用或未就绪时避免无用主队列投递；仅被 @ 才回复的群提前跳过普通未 @ 文字，保留图片暂存、后续 @ 提问和消息身份关联与去重。
5. **字体与缩放数值缓存。** 高频 getter 读取一致的原子快照，设置变化、恢复和激活时及时更新。
6. **定时任务后台持久化。** 加载、序列化、原子替换与文件／目录 fsync 在串行后台队列执行，主线程读取不可变快照；执行声明持久化后才发送，关闭、编辑、切号、过期或原生查询重入均可撤销待发资格。备份 preview／prepare 等待已接受的写入，保留 revision 校验。
7. **赞赏页降低检查频率。** 打开阶段保留 0.2 秒检查和 12 秒期限，展示后改为 2 秒兜底；失活或后台暂停展示检查，保留原生支付路线、完成回调及激活后的实际页面确认。

继续包含 `2.1-13` 的 AI 异步存储、上下文限额、角标合并及自动备份调度，`2.1-12` 的设置分组调整，以及 `2.1-11` 的密友消息静默移除和旧配置兼容。
