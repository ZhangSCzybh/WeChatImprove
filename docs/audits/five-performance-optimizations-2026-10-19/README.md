## 实现与证据

| 优化项 | 实现 | 测试证据 |
| --- | --- | --- |
| 全局文本匹配 | 提取 `CSCustomTextMatch`，先检查替换配置和简单文本特征，再执行匹配；三个正则表达式分别按需编译一次。保留 Unicode 数字、原正则尾部换行匹配及原有导航标题处理语义。 | 10,000 个普通文本不触发正则编译；命中相关路径后，三个模式各编译一次。 |
| 气泡边距分析 | 以不可变 `CGImage` 身份和 scale 缓存分析结果，持有原图防止指针复用误命中；对合适尺寸缓存不支持的分析结果；设置 128 项、4 MB 的缓存目标限制，并响应内存警告清理。 | 100 个新气泡单元复用同一原生背景，不增加边距扫描；像素图替换、深浅色、图片所有权与恢复逻辑有回归覆盖。 |
| 消息合并 | 在原生消息节点关联描述缓存，重复准备复用对象；仍校验消息身份、方向、发送人、适用性、账号和会话。应用或所属场景不活跃时暂停插件额外 UI 刷新，保留脏状态并在恢复后继续。 | 1,000 次重复准备不增加描述对象；覆盖同指针内容变化、相同数量替换、前后台和场景生命周期。 |
| 会话分组 | 同账号下复用未变化的行、分区和快照，变更时按需复制；结构及选择不变时复用显示与原生索引映射。完整保留行字段、顺序、路径以及分区数量校验。 | 600 行无变化时复用原快照；仅一行未读变化时只替换该行，其余分区继续复用；同数量重排与分类变化有覆盖。 |
| 导航头像和分隔图片 | 共享图片加载器、URLSession 和已解码缓存；文件读取及 ImageIO 缩略图解码在后台串行队列执行；同账号、来源和尺寸的并发下载合并。支持取消，最后一个订阅取消时取消网络任务；以绑定键及账号拦截迟到结果。 | 20 个订阅（其中 2 个取消）共用一次请求和解码；1,000 次未变化的头像更新不新增请求或解码；测试确认缩略图解码不在主线程。 |

分组优化减少对象分配和投影重建，**并未消除 O(n) 原生行读取与完整校验**。不依赖“仅未读变化”的提示跳过校验，避免漏掉同数量重排、置顶或分类变化。

导航图片缓存按账号、来源和像素尺寸区分；本地文件还包含大小、修改时间和 inode，读取后再次核对文件版本。远程缓存 300 秒后在下一次请求时重新获取，不进行定时轮询；失败不写入缓存。缓存设置 128 项、8 MB 的目标限制，并在内存警告时清理；缩略图最大边长限制为 512 像素。`NSCache` 的 count/cost 限制用于指导淘汰，并非进程内存硬上限。

导航分隔图片重新校验同一来源时保留已有图片，减少闪烁。设置预览原有同步读图接口仍保留，导航热路径改用后台加载器。测试使用合成 PNG 和自定义 NSURLProtocol，不访问真实头像网络地址。
