# 1.8-27 气泡字体颜色

在 1.8-26 基础上，气泡样式设置新增发送方和接收方的字体颜色。沿用背景色的主题结构，分别提供浅色发送方、浅色接收方、深色发送方、深色接收方四组设置。

入口为“气泡样式 → 自定义气泡 → 字体颜色”。点击对应项可选择“自定义颜色”或“跟随微信”。默认不覆盖原生文字颜色；自定义字体颜色为不透明颜色，顶部预览同步使用所选颜色。

背景与字体分成两个设置区，并分别提供“恢复默认背景色”和“字体恢复跟随微信”。逐项恢复只清除该方向、该主题的文字颜色；背景、圆角、样式和合并偏好继续保留。关闭自定义气泡时恢复插件接管的文字原色。

## 适配与恢复

[字体颜色适配器](../../../Controllers/CSBubbleTextColors.m) 在气泡适配器确认支持的消息模型后执行，仅访问消息内容控件：

- 正文通过 `getRichTextView`，引用正文通过 `getMsgReplyView.richTextView`，使用富文本控件的 `oTextColor` 颜色接口。
- 语音时长使用原生 `m_secLabel`。
- 通话记录优先使用直接内容接口；需要兼容查找时，仅遍历当前 Cell 的 `getContentView` 子树，最多 32 个节点。返回整个 Cell 或不属于当前 Cell 的内容视图时跳过。
- 调用私有颜色接口前检查方法参数和返回类型。富文本链接颜色属性保持原生；UILabel 的富文本副本保留链接、附件、字体和段落等属性，只替换普通文字前景色。
- 记录插件生成的颜色和富文本，恢复时只还原仍由插件持有的内容。微信更新了文字或原色后，保留新的原生状态；复用、关闭或切回“跟随微信”不会恢复成旧消息内容。

[生命周期 Hook](../../../Hooks/BubbleStyleHooks.xm) 覆盖文本和语音内容布局、语音时长颜色更新，以及已绑定富文本控件的原生颜色赋值。没有增加对全部 UILabel 的颜色 Hook。

## 缓存与布局

[配置策略](../../../Controllers/CSBubbleStylePolicy.m) 将完整偏好与背景偏好分别比较。仅字体颜色变化时，保留背景缓存和背景生成版本，直接刷新文字；回归验证了图片赋值次数、像素扫描次数均不增加。重复且无变化的布局不重复赋文字颜色或请求文字重绘。

新增字体颜色适配器不会修改文本、字体大小、内容布局或消息行高。与任务开始前逐字节比较，气泡半径/模板绘制函数、合并策略和合并适配器均未变化，结果见 [preservation.json](preservation.json)。

主要设置与预览实现见 [设置页](../../../Controllers/CSBubbleStyleSettingsViewController.m)、[效果预览](../../../Controllers/CSBubbleStylePreview.m)。跟随微信时，预览使用默认文字配色示意；实际聊天沿用微信原生颜色，自定义时预览使用确切的配置色。
