# 重置修复与设置页整理 · 1.8-39

本轮基于已回退的 1.8-37 工作区，修复图片缺失导致重置设置不可用，并按项目现有设置页组件整理备份、重置与预览页面。使用 1.8-39 避免覆盖历史 1.8-38 产物。

## 故障证据和实现

用户报错为“底栏样式：图片 xxx.png 无法完整读取……”。从修改前源码归档独立编译后，以不存在的底栏图片路径复现了完全相同的报错，见 [基线复现](baseline-reproduction.log)。旧版 resetSnapshot 先完整捕获当前配置，图片读取失败会在生成重置目标之前退出；只修改入口还不够，预览、准备和重启核验也会再次读取图片。

本轮为重置增加严格限定的缺失图片处理：

- 只对文件系统返回 ENOENT 的丢失图片放行，预览、保护快照及重启核验使用相同规则。现存但损坏、过大、权限不足或资源目录内符号链接仍报错，普通手动/自动/升级备份继续要求资源完整。
- 保护快照保存其余可读配置和图片，记录缺失图片路径并明确提示无法找回。联系人只有丢失的图片引用不进入可移植字段，其他联系人设置仍保存。
- 事务日志保留精确原始配置引用，执行中断仍可回到原状。预览修订值涵盖原始配置、可读图片及缺失清单；修改丢失路径或使图片重新出现会让旧计划失效。
- 仅清除用户选择的登记项，沿用账号归属、模块选择、启动应用、保护备份和回滚校验。未选模块里的丢失图片仍需修复，普通完整备份及升级保护不会因此放宽。
- 图片读取兼容受信任容器父目录的路径别名，仍拒绝资源目录内链接和越界文件。

## 页面变化

复用 CSSettingTableViewCell、CSSettingItem 和 CSSettingSection，使用现有图标、54pt 文本/分隔线起点和系统分组背景；未修改公共单元格。

- 重置页：选择重置范围、备份入口与功能说明，区分预览和真正准备执行。
- 备份页：备份设置、本机备份、恢复管理、说明四组；短状态与时间留在列表，详细信息通过原有弹窗展示，空列表给出可操作提示。
- 预览页：复用设置单元格，明确显示“预览重置 / 准备重置”；概览分行，缺失说明位于组尾，模块/账号使用勾选，变更详情点击查看。校验中、失败或没有差异时不启用提交。

保留创建、导入、分享、重命名、收藏、删除、自动备份、取消计划、重试与修复入口。
