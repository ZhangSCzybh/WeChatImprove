## 使用与效果

进入 **底栏样式 → 样式设置 → 切换点击特效**，该项位于“切换触感”下方。先启用悬浮导航栏，再选择“轻弹”；默认关闭，保存后即时生效。

成功切换到其他标签后，选中图标按 `100% → 92% → 108% → 98% → 100%` 缩放，并按 `0 → 0 → -4 → +1 → 0 pt` 轻微上弹、回位，合计 0.34 秒。文字、角标、底栏背景和按钮点击区域保持稳定。自定义导入图标与微信原生自定义图标视图均可作为动效目标。

重复点击当前标签、程序切换页面、仅有松手而没有对应按下事件均不播放。快速连续切换会取消上一段动效，并丢弃已经过期的排队反馈。关闭功能、底栏隐藏或离开窗口、微信或窗口进入非活动状态、系统减弱动态效果、严重温控状态都会停止相应动效；恢复可见时不会自动补播旧的点击。触感与点击动效独立配置。

## 框架接入

沿用现有 Theos / Objective-C / Logos 框架和原生底栏逻辑：

- `Hooks/TabBarStyleHooks.xm` 继续转发微信原生布局、选中和显示生命周期，本次不增加切页 Hook，也不替换导航控制。
- `CSTabBarNativeAdapter.m` 在原生按钮松手回调后的主队列时机，确认确实切换到该按钮对应的页面，再播放一次动效。使用触摸代次和按钮身份检查防止旧回调误触发。
- 动效采用独立名称的 Core Animation additive transform，起止为单位变换，不写入图标 frame 或底层 transform。清理时只移除本功能的动画，保留原生动画。每次普通布局不重新提交动效。
- `CSTabBarPreferences` 统一读取 `com.wechat.enhance.tabbar_style.click_effect`，`0` 为关闭、`1` 为轻弹；缺失或未知值均按关闭处理。设置页纳入保存、重置及即时刷新通知。
- 新配置纳入 `CSBackupRegistry` 的标准 defaults、`tabbar` 模块、全局数值字段，沿用既有备份恢复路径。配置登记表同步更新。
