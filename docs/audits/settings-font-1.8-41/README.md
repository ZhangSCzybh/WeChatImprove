## 框架与功能逻辑

项目使用 Theos 构建 Objective-C / Logos iOS 微信注入插件。`Hooks/` 接入微信生命周期和私有接口，`Controllers/` 实现设置页、业务策略和原生适配。设置页主要使用 `UITableViewController`、`CSSettingItem`、`CSSettingSection` 和 `CSSettingTableViewCell`；原插件入口通过 `CSNativeSettingsHost` 承载完整设置首页。

备份和重置的调用链是：设置页 → `CSBackupManager` 异步接口 → `CSBackupEngine`。登记表限定可以读取、备份、恢复和重置的插件配置；Codec、Assets、Store 分别处理格式、图片和快照/事务存储；Scheduler 处理自动备份，Bootstrap 处理启动恢复边界。

- 创建备份保存已登记的配置、自定义图片和账号分组。导入仅保存备份文件，不直接应用设置。
- 恢复和重置共用预览页面：选择模块与原所属账号 → 计算差异 → 保存保护备份 → 准备待执行计划 → 重新打开微信时校验和应用。
- 预览中的账号/配置变化校验、保护快照、取消计划、中断回滚及已有图片缺失处理均沿用现有实现。
- 配置来自微信进程的标准偏好域、`com.cyansmoke.wechattweak` 和 `com.wechat.enhance`；备份存放于微信容器 `Library/Application Support/WeChatImprove/BackupV2/`。本次没有接触设备容器或真实偏好数据。

## 字号差异与修正

源码可以确认两处实现差异：

1. 备份、重置和预览中的操作行使用 `actionItemWithTitle:`，公共单元格的 `configureActionItem:` 会显式将标题设为 17pt。参考页面“自动收款”的列表行采用普通设置项和开关项，普通行不执行该字体覆盖。
2. 原备份/重置/预览页使用带 `forIndexPath:` 的出队接口，参考页采用不带该参数的接口。

本次将这些页面统一为参考页的普通设置项与出队方式，不猜测或硬编码截图对应的字号。操作回调仍由原 `didSelectRowAtIndexPath:` 调用，箭头单独保留。自动备份继续使用原开关类型，预览继续使用原生勾选。没有修改公共单元格、自动收款页面或全局字体 Hook。

截图确认了显示差异，源码确认了上述配置路径差异；由于未运行手机 UIKit，不能把这些检查表述为最终屏幕字号已实测一致。
