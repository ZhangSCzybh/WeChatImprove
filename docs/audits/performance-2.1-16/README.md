## 实现与保护边界

1. **AI 消息入口**：按账号 epoch 发布不可变启用会话集合，已知未启用会话不再进入额外主线程任务；未知会话形态继续走原解析。主线程配置、身份、去重及发送授权检查保留。
2. **折叠入口摘要**：原生对象、文字、几何及主题状态均一致时复用已拥有的前缀标签；条件变化重走原生渲染。每次仍检查账号、隐私、隐藏修复及渲染后的有效性；未知主题接口保守禁用复用。
3. **备份库存**：同一次保存内复用验证记录和匹配的自动备份快照。重新枚举并核对文件身份，变化项重读；独立清理不计算未使用的内容摘要。操作结束清空库存；删除前继续重验元数据、恢复事务及文件身份。
4. **共享备份图片**：单次资源处理先复制唯一图片的实际字节，再校验一次散列及 ImageIO；每个引用继续验证格式、目标路径与冲突。编码、解码及采集一致性保护保留，独立资源处理也自行验证。
5. **折叠列表定位**：按账号、epoch 和模型版本复用 Foundation 坐标索引；旧路径或索引命中仍核对当前原生身份，失配重新扫描。保留最终动作及隐私判断，不凭同指针或同数量认定源数据未变。
6. **导航头像弹窗**：信息弹窗和联系人分隔符设置复用共享缩图加载器，页面先显示占位；退出、复用或身份失效取消请求，回填核对账号、联系人、URL、当前页面及目标视图。
7. **附件布局**：按场景、聊天标识和配置代次预计算排序、隐藏及可见序号，设置变化或下次原生布局重新读取。保留原生调用副作用、关闭后的原生返回、未知索引及默认初始化语义。

备份列表同时包含此前完成的手动删除修复：收藏、无法读取、非标准文件名等已列出的备份可确认后删除，删除限定于目录内的单个备份文件或链接；恢复事务正在使用的文件及无法确认的事务状态继续保护。
