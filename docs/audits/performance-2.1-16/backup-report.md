# 备份库存与共享图片性能优化

日期：2026-10-29。修改和验证对象为当前工作目录中的生产源码，保留既有 2.1-15 优化及随后实现的手动删除修复。未修改真实账号、微信消息数据库、用户偏好或用户备份；测试均使用临时目录、隔离 suite 和替身账号。版本、构建及打包由根任务统一负责。

## 修改

`CSBackupEngine.m` 的一次 `save` 在 capture 成功后进入 Store 库存作用域。`CSBackupStore.m` 每次仍重新枚举当前目录；只有路径及设备、inode、类型、大小、纳秒 mtime、纳秒 ctime 都相同的文件才复用已验证记录。变更、增加、移除、损坏和迁移文件重新识别。记录读取前后也核对身份，正在变化的文件作为不可读原件保留。

库存只保存摘要记录及同账号、同安装来源的一份最新自动快照，不保留全部解码历史。去重返回前再次确认该文件身份。作用域在 `@finally` 中清除，包含错误和异常退出，不在两次保存间复用。发布后的清理复用原历史记录，只完整读取新发布或变化的文件；独立清理不再计算保留策略不需要的 `contentDigest`。

自动清理仍在执行前读取收藏、导入、冗余 metadata 和活动事务。内部受保护删除在最终 `fstatat` 后核对原候选身份，避免已经变成其他备份或损坏文件的候选被按旧记录删除。删除仍通过目录 fd 和 `unlinkat(...,0)` 操作，仅允许普通文件或链接本体；手动删除 API 和异常原件删除功能继续保留。迁移屏障、保留数量、不可读原件保护及持久清理审计保持有效。

`CSBackupAssets.m` 将单次物化中的唯一资源校验集中到入口。每个资源的散列和 ImageIO 校验只做一次，每个引用仍独立验证语法、资源存在性、所有权及目标冲突。`immutableAssets:error:` 使用 `initWithBytes:length:` 真正复制资源字节，避免 `NSData copy` 保留映射文件；每次独立调用重新验证，无跨调用图片验证缓存。复制前保留每项 4 MiB、总计 24 MiB、256 项限制。

`CSBackupCodec.m` 在编码前冻结待封存资源，保留结构、资源限额、字段、整体 integrity、编码后解码检查；唯一资源的散列和图片校验交给同一次物化验证，去掉原有的重复校验。原有两次 capture 和三次重试完全保留。

## 调用计数

前值来自 `docs/audits/performance-followup-2.1-15.md` 已有隔离实测，本轮不重新构建旧实现。后值由 `Tests/BackupPerformanceTests.m` 子类计数并转发当前生产 `snapshot:error:`，以及在独立测试进程替换并转发当前生产 `validImage:` 获得。所有功能逻辑仍执行生产实现。

| 手动历史 N | 不变自动保存：原值 → 当前 | 变化自动保存加清理：原值 → 当前 |
| --- | --- | --- |
| 0 | 2 → 1 | 3 → 2 |
| 20 | 22 → 21 | 43 → 22 |
| 80 | 82 → 81 | 163 → 82 |

| 唯一图片 | 共享引用 R | 一次 encode 的 validImage：原值 → 当前 |
| --- | --- | --- |
| 1 | 1 | 2 → 1 |
| 1 | 20 | 21 → 1 |
| 1 | 100 | 101 → 1 |

独立 decode、独立 materialize 仍各验证一次全部唯一资源。两个唯一资源验证两次，未引用的损坏资源也被拒绝。计数不代表整次保存只解码一次图片；capture、encode、decode、publish 仍有各自独立验证阶段。

## 回归

新增性能与边界测试 342 项，覆盖实际自动去重、账号和安装来源隔离、发布失败不清理、scope 正常和异常清除、同名替换、同长度且恢复 mtime 的替换、原位变化、增加和删除、晚到的旧目录迁移、删除前收藏、导入、事务、metadata 或日志损坏、文件替换、独立 prune 不算内容摘要、共享图片引用、独立物化、目标冲突、缺失／损坏／散列错误资源、可变 NSData、映射文件、未引用坏图，以及每次外部图片变化时原有三次双 capture 拒绝混合快照。

已运行受影响的现有回归：assets 26、codec 16、engine 25、store 52、retention 171、transactions 89、deletion 140、deletion UI 480、restore paths 249、passive audit 43、plugin storage migration 84。日志为同目录 `backup-*.log`。

验证边界：本轮是 macOS Foundation / ImageIO 生产实现的宿主回归，没有真机能耗或帧率测量，也没有宣称固定速度、温升或耗电收益。库存仍需至少完整读取和验证一次历史；物化与编码冻结字节增加有界的内存复制。文件身份检查用于发现操作中的变化，没有将文件系统操作宣称为可防任意并发改写的原子事务。
