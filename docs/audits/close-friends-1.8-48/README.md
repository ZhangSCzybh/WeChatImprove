# 密友真机反馈修复 · 1.8-48

基于 1.8-47（`2953a2ad4eb2f7193dfca48d7c87c454d242b6d8`）完成本轮四项修复，产物为 Rootless、arm64/arm64e、最低 iOS 15.0。

| 反馈 | 修改后的行为 | 关键实现 |
| --- | --- | --- |
| 从分组进出搜索闪到“全部” | 搜索转场保留当前分组、标题和标签；搜索中锁定／解锁仍按同一分组刷新 | `CSGroupListAdapter refresh` 不再因密友保护绕过分组保留分支 |
| 密友个人朋友圈整页解锁提示 | 沿用微信原生页面，封面、头像、昵称、签名保持原生；密友动态区域为空，调用原生横杠终止视图 | 新增 `CSCloseFriendAlbumAdapter`，移除 Moments 整页 gate；通过微信已有分支进入原生可过滤页面 |
| 发现页朋友圈仍有密友互动角标 | 真实朋友圈行计数和 Tab 聚合扣除密友互动；普通好友互动保留 | 补 `getSnsMessageCount`，按微信自己的 Related/Mutual 分区扣减，只修改展示计数 |
| 自己朋友圈详情仍有密友点赞评论 | 原生详情点赞与评论列表过滤密友，锁定／解锁同步刷新，普通评论点击、回复索引保持正确 | 新增 `CSCloseFriendDetailAdapter`，过滤详情直接读取的页面缓存数组，原始引用在绘制后恢复 |

主列表、个人页、自己的相册和详情不再注册整页“解锁后查看”封面。微信版本存在原生与 Flutter 多条路由；本次使用已核实的微信原生分支，不自建个人朋友圈或详情页面。临时解锁期间保持同一原生分支，重新锁定后能够刷新已打开页面。

真实好友关系、动态、点赞、评论、发布权限和原始未读消息保留。本轮没有修改已交付的原生搜索联想、完整密码解锁或来电挂断回复逻辑，也没有在手机安装或发送真实消息。
