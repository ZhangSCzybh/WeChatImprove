## 使用方式

入口是 **插件设置 → 账号与安全 → 密友**。首次配置独立密码，添加密友或密群后启用。默认临时显示 300 秒；返回后台、切换账号、重启或主动锁定会重新隐藏。主动隐藏入口后，可长按微信首页顶部导航栏 1.2 秒验证进入。

临时显示恢复原生列表，消息提示继续按静默选项处理，语音和视频拒接分别受对应开关控制。朋友圈分组可见图标的隐藏独立于临时显示状态。

## 使用限制

- 接口静态依据来自微信 **8.0.78**，运行时还会校验方法签名。自动免打扰的原生写入仅在该已核对版本启用，其他版本不猜测 BOOL 语义。
- 主 ilink 没有精确匹配子通话缓存、部分统一群邀请广播等路径尚无已确认的安全拒接实现。它们保持 `rejectionUnsupported`，不能把提示消失视为电话已经拒绝。普通群主邀请使用独立的精确房间路径。
- 当前只注入微信主进程。进程终止或挂起时的 APNs、通知扩展、锁屏 CallKit 首帧，以及不能可靠归属身份的异步输出，不在已验证覆盖范围。PushKit/CallKit 必需生命周期回调保留。
- 个人朋友圈、部分详情/Flutter/直接状态入口采用验证后查看；隐藏状态下部分删除、整页已读和发布范围编辑受限。发现页朋友圈的头像/红点等提示可能显示为中性状态，普通内容的相应提示也会暂时减少。
- 会话来源过期、未知聚合或尚未加载时，公开角标暂时显示中性值，可能少显示普通未读；不会通过清除真实未读来隐藏密友。
- 免打扰修改若绕过所有已观察原生 setter，且最终值与原值相同，无法证明发生过外部修改。为防止写入失败后旧恢复归属重新生效，自动恢复只限当前微信进程内仍能确认归属的修改。**微信重启后，再移出密友或停用功能，先前自动设置的免打扰可能保留，需要在微信里手动关闭。**
