## 最终行为

按本轮更正，输入两位数字或任意普通内容时，原生实时联想、“搜索网络结果”、加载和搜索提交照常工作。密友保护所生成的“解锁后查看”占位行不再显示。完整密码精确匹配后仍自动解锁、清空可见输入并取消本次搜索；再次输入普通内容立即进入原生实时搜索，无需新增确认或额外按键。

两个占位行原来分别由受保护的消息与扩展搜索分类强制返回一行生成。本次将对应可见项数改为零，删除占位单元格和占位解锁动作，同时防止旧行的点击／加载回调进入被隐藏内容。原有密友结果过滤继续生效，临时解锁后原生分类恢复。

撤回 1.8-45 的全部输入暂停策略及显式提交时补发查询的行为。现有输入、语音、延迟查询和历史入口只在完整密码匹配及其清理阶段拦截；原生联想和网络提示不会因为输入尚未完成而被整体清空。设置说明和本版发布说明已同步。
