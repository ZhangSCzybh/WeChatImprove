# 密友独立完整重置

日期：2026-10-26。分支 `codex/close-friend-entry-gesture`，开发版本 `2.0-13+entry2`。在手势入口版本 `463cb17b` 上继续开发，沿用本任务的独立工作树；原 `main` 工作目录未切换、未覆盖。

## 操作与范围

密友页底部新增独立的“重置密友”分组和操作行。点击后先输入当前密友密码，通过后再次确认。首页手势或生物识别获得的临时授权不能直接用于重置。密码错误沿用已有失败计数与冷却限制。

确认后清空当前微信账号的密友／密群名单、所有保护选项、历史密友免打扰记账、密码及其错误计数、加密密钥、生物识别基线、入口发现记录。运行时授权、搜索校验缓存及待完成的认证令牌一并失效。保护关闭，退出密友页，“捉迷藏呀”入口恢复首次隐藏；再次长按插件主设置页顶部头像 2 秒可发现入口，并设置新密码。

只清理当前账号的密友插件数据。不删除微信好友、群聊或聊天记录，不修改微信原生免打扰，不影响其他账号或通用插件设置。普通“重置设置”和备份注册表未接入密友重置。

## 中断与账号保护

`CSCloseFriendRuntime` 在密码验证后生成一次性重置证明，确认时再次核对账号、epoch、generation、前台状态和授权期限。取消、退后台、账号切换、修改密码或过期后不能继续使用旧证明。确认及启动恢复都在既有账号 epoch 锁内执行。

`CSCloseFriendReset` 先在当前账号的 Keychain 项 `reset.<账号 SHA-256>` 写入并回读 `close-friends-reset-v1` 标记，才开始清理。标记不包含密码或名单，沿用 `WhenUnlockedThisDeviceOnly` 和不启用 iCloud 同步的属性。清理顺序为：完成旧目录迁移 → 删除当前账号密文并 fsync 目录 → 清除并同步入口发现偏好 → 删除生物识别、密码及策略密钥 → 最后删除重置标记。

任何步骤失败都会保留重置标记，暂停当前账号的密友配置；下次进入该账号时先续完已经确认的重置，再加载账号。标记不可读或格式不正确时保持阻断，不能按首次使用处理。文件清理失败时保留加密密钥；旧目录冲突、符号链接或其他不安全路径不会被强行覆盖或删除。标记写入前失败不清理原数据，用户可重新验证并重试。
