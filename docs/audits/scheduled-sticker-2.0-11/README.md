# 2.0-11：定时任务与会话图片添加到表情

本次在现有消息操作框架上增加两项功能，时间规则包含用户补充的“每 N 分钟”。功能说明、存储/后台限制及真机验收见 [使用说明](../../features/scheduled-tasks-and-image-stickers.md)。

## 核心回归

| 入口 | 断言数量 | 覆盖 |
| --- | ---: | --- |
| `verify-scheduled-tasks.sh` | 102 | 分钟/小时锚点、单次、每天/每周、时区与夏令时、总开关、账号隔离、重启去重、错过/有限补发、原子持久化失败和损坏原件保留 |
| `CS_TEST_SCHEDULED_STICKER=1 verify-message-actions-execution.sh` | 178 | 全新文字消息提交、私聊/群聊/filehelper 目标、菜单启停/去重/消息类型、实际图片 hook、原生过滤、同步/异步结果、重复点击、切账号/关闭开关/消息复用、下载相关性、普通文件读取、原复读/语音菜单兼容 |
| `verify-message-actions-core.sh` | 1366 | 共用策略、设置刷新、上下文、提交状态；图片开关独立生效且不改变已保存手势枚举 |
| `verify-backup-registry.sh` | 1404 | 新开关登记及原有配置键约束 |
| **合计** | **3050** | 本机隔离数据、原生替身，无真实发送/上传 |

没有运行项目全量脚本。共用菜单发生必要扩展，因此包含该层已有复读/语音/表情菜单用例；登记了一个新的配置键，因此运行较小的备份注册表检查，没有扩大到备份恢复事务回归。

针对性用例先复现了一个实际规则问题：Darwin 的向后日历查询在秋季夏令时回拨时可选到第二次 01:30，导致“最近一次”与“下一次”计算不一致。现在按同一本地日期向前求第一次时刻，DST gap/fold 用例通过。iOS 首次编译还发现 BOOL block 的推导类型为 int，已显式声明 BOOL 并重新构建通过。初次编译日志保留于 `build-rootless-initial.log`。

执行链路额外核对了两套账号生命周期：图片操作保存开始时的 Backup epoch，在原生提交锁内验证未注销且代次一致；原生异常在锁内捕获，再于锁外处理反馈，避免异常绕过锁释放。

## 构建与包校验

版本常量、control、内置更新说明和 README 同步至 2.0-11。复用之前独立的 rootful/rootless Theos 缓存，未执行 `make clean`，未改动用户原有 `.theos` 构建状态，2.0-10 产物保留。具体目录及旧产物摘要见 `build-environment.json`。

最终构建日志为 `build-rootful-final.log` 和 `build-rootless-final.log`。最终包核对包含版本、包架构、dylib arm64/arm64e 切片、新功能符号、启动时存储迁移初始化函数顺序、测试替身未入包，以及各切片的 dSYM UUID。结果及 SHA-256 见 `packages.json`，源码摘要见 `source-sha256.json`。原有弃用 API 与链接器警告保留，本次新增代码无剩余编译错误。

此版本交付为本地安装包；没有提交或推送 GitHub。当前环境未连接真机，不能把编译成功或原生替身回调成功写成微信实际发送/上传已验收。
