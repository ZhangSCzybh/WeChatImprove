# WeChatImprove 2.5-13+online.3

本包对后台消息网络活动路径作了实际调整，验证“有后台执行机会时，群拍动实时回拍／回复”。尚未在用户手机上确认持续后台和锁屏效果。

文件：`com.wechat.improve_2.5-13+online.3_iphoneos-arm64.deb`。Rootless，iOS 15+，arm64 / arm64e。

1. 安装并重新启动微信，确认插件版本为 2.5-13+online.3。
2. 保持有效群回拍／回复配置，业务延迟设为 0。
3. 在“自动功能”底部先开始采样，再开启“测试后台实时接收”。默认关闭，10 分钟自动关闭，重启或切换账号后也需重新开启。
4. 可沿用 HBB 后台常驻，本插件“后台运行”可关闭；也可使用本插件保活。分别进行后台与锁屏的多次测试，在发送端观察回复。测试后停止并导出采样。

仅适配已核对的微信 8.0.80.34 主程序 UUID，入口指令不匹配时会拒绝开启。测试影响微信整体网络活动，可能增加耗电或改变通知表现；关闭、到期、资格失效时释放实验覆盖，回前台由微信自然状态接管。不新增周期性补拉，不修改系统应用前台状态。
