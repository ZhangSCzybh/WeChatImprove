# 2.5-13+online.2：兼容其他保活方式的群拍动验证包

修正 online.1 只承认本插件自身后台资源的限制。**可以继续使用其他插件保活，无需同时开启本插件“后台运行”。** 本包仍需在自动功能页面手动开启“测试后台在线模式”，开关默认关闭。

用户反馈 online.1 使用其他保活方式时无回复，开启本插件后台运行后则立即回复。失败日志证实前一种情况下实验开关开启、群配置有效，但内部后台资源检查为 false，整轮没有发出实验在线请求。本版去除这个错误依赖；其他保活方式的手机实效待本轮验证。

## 安装和测试

1. 安装本目录 `com.wechat.improve_2.5-13+online.2_iphoneos-arm64.deb`，按包管理器提示重新加载微信，确认版本为 **2.5-13+online.2**。包适用于当前 Rootless、iOS 15+、arm64 / arm64e；实验原生接口针对微信 8.0.80。
2. 保持你原来的其他插件保活方式，**本插件的“后台运行”可以保持关闭**。目标群开启回拍或拍动回复，执行延迟为 0。
3. 在“自动功能 → 群拍动接收模式验证”先开始采样，再打开 **测试后台在线模式**。接收端退后台并锁屏，只在群里拍一次；观察约 30 秒，这期间不私聊拍接收端、不打开接收端前台。
4. 记录是否立即回复。随后回前台，关闭实验开关并停止导出，文件名前缀为 `WeChatImprove-2.5-13-online2-`。若仍失败，注明是否回前台才回复。

测试开关只在本次微信运行有效，10 分钟自动关闭，重启或切换账号会关闭；系统挂起时关闭及恢复也只能在重新执行后处理。采样默认关闭，最多 10 分钟／4000 条，保存在内存；不包含账号、群号、消息正文或 XML。

## 这次实际修改

实验从“本插件拥有有效保活资源”改为“当前回调确实在主线程执行、微信处于后台”，同时继续检查群配置、账号、授权、服务身份和请求代次。它不需要读写其他插件设置，不会代替其他插件提供保活，也没有新增周期性补拉。

本插件自己的后台资源消失不能说明其他方式已经停止保活，因此不再单凭本插件资源状态自动撤销实验。手动关闭、配置失效、到期、前台接管、账号或服务变化的保护仍然生效。微信被系统挂起或进程退出时，任何这类回调均无法运行。

在线状态上报仍作用于当前微信连接，可能影响耗电及通知表现。出现异常时关闭测试并回到前台，或重启微信。可回退 [正式 2.5-13 Rootless 包](../2.5-13-pat-service-wrapper/com.wechat.improve_2.5-13_iphoneos-arm64.deb)。

源码、验证记录与这份手机日志的分析见 [审计说明](../../docs/audits/pat-online-experiment-2.5-13-2/README.md)，成品哈希见 `SHA256SUMS`。正式生产源码保持 2.5-13，实验以独立包及补丁归档。
