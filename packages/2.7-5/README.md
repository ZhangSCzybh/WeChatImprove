# WeChatImprove 2.7-5

发布日期：2026-11-20。本正式完整版整合设置首页、顶部卡片、Tab 导航、搜索、切换动画与界面调色优化。提供 Rootless、Rootful 两种安装包，均包含 arm64、arm64e，最低 iOS 目标为 15.0。

## 更新内容

- **重整首页功能导航**：设置首页按账号、美化、增强、设置四个 Tab 展示功能，每页均保留版本信息与支持作者。右侧搜索按钮在当前 Tab 栏位置展开输入框，搜索与取消保持浏览位置，并修复展开时的上移和 Tab 残影。
- **加强功能组切换动画**：功能组的标题、背景和设置项整体上移入场，旧组下移淡出，增大运动幅度并加快过渡，各组错峰衔接。快速切换及时清理旧动画，开启减少动态效果时使用简短淡入。
- **完善界面调色**：默认绿色更新为 #05944A，保留蓝色、紫色、橙色和自定义取色，选择结果自动保存。Tab 选中文字与预设色选中对号统一为白色，功能图标、右侧箭头圆形底色和文案引号跟随主题；版本信息与支持作者保持浅金色。
- **优化顶部卡片与随机文案**：顶部账号、文案和状态区域增加留白并适度放大文字，保留固定浅金色 SVIP 标识和三张等宽等高状态卡片。文案仅在重新进入插件时刷新，停留期间下拉、切换 Tab、搜索或从详情返回不重复请求，继续保留双来源正文提取与失败回退。

包版本、插件内版本和当前更新说明统一为 `2.7-5`。本次仅更新正式版说明，历史版本说明与安装包保持原样。

## 验证范围

聚焦首页导航与原位搜索、功能组整体切换和快速切换清理、减少动态效果、主题保存与恢复、顶部卡片布局、主题引号、文案刷新边界及原有核心入口。当前更新说明、版本号、下载路径与历史说明保留情况同步核验，实际结果见回归与构建记录。

本版保留当前动画配置：旧组下移 160pt 并在 140ms 内淡出，新组从下方 210pt 在 200ms 内入场，错峰后整体最长约 250ms。

基于当前完整源码，在原项目 checkout 使用独立临时构建目录，保留现有 `.theos` 和历史发布文件。测试使用隔离临时数据与界面替身。

本轮未安装或重启原设备微信；最终视觉和原生触摸效果仍需在原设备、原注入环境验收。
