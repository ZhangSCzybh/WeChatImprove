# 后台运行重构：IPA 注入交付

构建标识：background-run-20261023。本目录为基于 `1.9-10` 构建的历史 IPA 注入产物。项目当前版本已更新为 `2.0-1`，本目录的动态库和压缩包仍对应原构建版本。当前版本信息与安装包入口见[项目说明](../../README.md)。

## 使用

1. 使用原来的 IPA 注入工具，替换 IPA 中旧的 WeChatImprove.dylib，避免重复注入两个版本。
2. 保留原来可用的 Substrate 兼容运行库。本库依赖 @rpath/CydiaSubstrate.framework/CydiaSubstrate，搜索路径包括 @loader_path 和 @executable_path/Frameworks；无需越狱系统目录。
3. 由原签名工具连同 IPA 和内嵌依赖重新签名。本文件的临时签名已经校验，但不能代替设备安装所需的 IPA 签名。
4. 在原账号、原应用数据环境中更新，进入“后台运行”确认开关和“后台音频支持”。支持项为未声明时，需要注入／签名包的 Info.plist 包含 UIBackgroundModes 的 audio 项；插件不会运行时伪造该声明。

启用后切入后台，返回设置查看“上次后台运行”。状态只表示本机音频启动结果，不能证明持续存活或交易到账。

## 本次变化

- 使用应用／场景生命周期和音频事件驱动，不再周期检查或循环申请后台时间。
- 插件生成 8 秒、16 kHz、单声道 16-bit PCM 静音数据并复用，不依赖微信 blank.caf。
- 前台和关闭时释放播放器；微信接管音频或系统中断时让出；明确释放／允许恢复后尝试恢复。
- 失败不持续重试，移除触发间隔输入，保留原开关和旧备份兼容。
