# WeChatImprove 3.0-1 完整版

本版汇总 2.9-11 系列更新，保留 beta06 的全部功能和已保存配置，统一插件显示版本、安装包版本与发布说明为 3.0-1。

## 主要内容

- 底栏提供经典悬浮、分离功能键、居中功能键三种结构，开关下方提供紧凑实时预览，设置按功能分类。
- 功能键可独立选择快捷面板现有 21 个入口。分离模式支持 0–32pt 间距、44–72pt 按钮大小，增大间距保持主栏宽度；居中模式支持 75%–180% 大小比例与轻度叠放。
- 底栏宽度支持 176–1024pt、高度支持 44–80pt。手动尺寸即时保存并优先生效，重新进入页面保留原值；宽度留空或 0 使用自动比例，实际显示受宿主宽度限制。
- 三种快速风格仅在主动选择时应用默认宽高，选择列表只显示名称。底部功能说明点击后通过弹窗展示。
- 沿用语音转文字发送后的连续消息合并与间距适配，保留原生发送动画及气泡配置。
- 完整保留聊天分组、界面定制、朋友圈布局、消息增强、自动回复、快捷面板、人工智能、定时任务、红包与收款、密友保护和备份恢复等全部既有模块。

| 快速风格 | 默认宽度比例 | 默认高度 |
| --- | --- | --- |
| 紧凑低调 | 60% | 54 pt |
| 均衡默认 | 75% | 60 pt |
| 舒展高光 | 90% | 62 pt |
