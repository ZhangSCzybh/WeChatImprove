# 2.9-1 聊天分组胶囊点击衔接优化

基于 `/Users/zhangshichao/Documents/Workspace/WeChatImprove` 当前完整工作区构建。插件内显示版本与安装包版本统一为 **2.9-1**。

## 本次修正

旧实现把胶囊放在每个标签内部，通过各自缩放、淡入淡出完成切换，松手后接0.28秒动画。本版改为一个持续存在的背景胶囊，在分组之间连续移动；按压、松手和连续点击使用与底栏相同的 UIKit 动画接口及参数。

| 阶段 | 配置与行为 |
| --- | --- |
| 手指按下 | 0.12秒 EaseOut；共享胶囊移动至目标触点并微扩，标题与未读角标不缩放 |
| 松手归位 | 0.46秒弹簧，阻尼比0.62，初始速度参数0.82 |
| 快速连续点击 | BeginFromCurrentState 从当前呈现状态接续；不先重置到旧分组或重播出现动画 |
| 被动刷新 | 目标几何未变化时不重启胶囊动画；点击提交前保留按压状态，避免布局刷新打断衔接 |
| 取消与横滑接管 | 恢复实际选中项或交给横滑进度；旧按钮抬手不覆盖手势结果 |

分组静止尺寸、颜色设置、字体、未读角标、稳定分组ID及原有业务选择时机继续保留。Down仅预览，Up提交一次分组选择；同分组点击只回弹，不重复选中或触发切换触感。横滑沿用原有判定与业务提交，胶囊背景改为单个连续位置插值。减少动态效果、关闭分组动画或离开窗口时直接落位。

底栏保持2.9-0的交互：拖动从A经过B到C期间只预览，松手只提交最终有效项目C，不切换中间页。
