# WeChatImprove 3.0-2 完整版

本版在 3.0-1 完整版基础上优化底栏宽度比例输入与分离功能键大小，保留全部既有模块和已保存配置。插件显示版本、安装包版本与发布说明统一为 3.0-2。[3.0-1 安装包](../3.0-1/README.md)及其[审计记录](../../audits/3.0-1/README.md)继续保留。

## 主要内容

- 底栏宽度改为按可用宽度的百分比输入，支持 60–100%。输入 `80` 表示 80%；留空或输入 `0` 恢复默认 90%。窄屏继续保留必要的最小宽度，预览与实际布局共用几何计算。
- 旧版保存的 176–1024pt 宽度继续兼容。打开设置页不会写入配置；只有主动编辑宽度比例或选择快速风格时，才清除旧 pt 宽度覆盖并切换为比例布局。
- 分离功能键大小范围扩展为 44–80pt，预览按相同 80pt 上限适配。间距仍支持 0–32pt，调整间距时保持主底栏宽度，接近屏幕边缘时限制实际扩展范围。
- 保留用户已设置的三种快速风格及其默认宽高，选择列表只显示名称。主动选择时同时应用宽高；手动尺寸即时保存，重新进入页面保留当前值，不匹配预设时显示“自定义”。
- 经典悬浮、分离功能键、居中功能键三种结构继续包含。功能键可独立选择快捷面板现有 21 个入口；居中模式保留 75%–180% 比例、描边、阴影和轻度叠放。
- 完整保留语音转文字连续消息合并适配，以及聊天分组、界面定制、朋友圈布局、消息增强、自动回复、快捷面板、人工智能、定时任务、红包与收款、密友保护和备份恢复等既有模块。

| 快速风格 | 默认宽度比例 | 默认高度 |
| --- | --- | --- |
| 紧凑低调 | 72% | 54 pt |
| 均衡默认 | 80% | 60 pt |
| 舒展高光 | 90% | 62 pt |

- 底栏核心回归通过：几何、选中图标与原生恢复、Neo 97 项、现代原生层级累计 121 项触摸检查、结构生命周期 1151 项，以及偏好与原生生命周期。
- 新增检查覆盖 80pt 与超上限、44pt 主栏搭配 80pt 按钮的上下边缘命中，以及三种结构、双方向的 60%／80%／100% 宽度和旧 pt 覆盖清除。备份注册通过 2459 项断言，包含 80pt 接受、81pt 拒绝。
- 设置页、偏好、预览、备份注册与内置发布说明通过 iOS arm64／arm64e 严格语法检查。Rootless、Rootful 各完整编译 298 个源单元、两种架构共 596 步，均为 0 error，各 8 条 warning 与 3.0-1 一致。
- 包版本、注入路径、双架构、最低 iOS 15.0、staging 库哈希、四组 dSYM UUID、符号 ZIP 及 SHA-256 均已核验，具体记录见[本轮审计报告](../../audits/3.0-2/README.md)。
- 使用独立临时构建目录，本轮开始前的 1461 个 `.theos` 缓存与安装包文件保持原哈希，3.0-1 及已有零散安装包均保留。

本轮未安装原设备，底栏画面、触摸体验及与其他插件共存的效果仍需在原设备、原账号和既有注入环境确认；主机回归与编译结果不代表真机验收结论。
