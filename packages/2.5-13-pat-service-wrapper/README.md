# 2.5-13 修复群后台拍动的服务代理识别

基于 2.5-12（`e0dfcb12`），修复用户反馈的“群聊拍动在后台／锁屏要回到前台才回复，私聊后台仍正常”。这是上版事件同步接入中的服务身份错误，本版继续采用事件驱动，并修正真实微信服务代理的处理。

## 确认原因与修改

微信查询返回的是 `MMServiceWrapper`，Hook 收到的是内部实际的 `NewSyncService`。上版直接比较两个对象的指针，会把有效服务误判为不匹配；配置／生命周期唤醒也不识别代理。与此同时，补拉计时器已因 Hook 安装而停止，导致群拍动等待其他原生同步机会。

本版只读核对受信代理所指向的实际服务，继续保留账号、epoch、授权、配置和后台状态检查。发起同步时仍使用**当前微信代理**，由它安装并恢复账号上下文；不会直接绕过代理调用内部服务。配置／生命周期唤醒同样支持代理。

只有当前服务实际具备事件路径能力才停止兼容补拉；能力暂不可用时保留原有兼容恢复机会，恢复后立即处理已有需求并停止计时器。**正常事件路径不等待 10 秒轮询**。回拍／文字回复、会话名单、持久去重、用户延迟、撤回与 AI 策略保持。本版没有新增运行时诊断采集。

原生函数证据、实现边界及上版遗漏的测试问题见 [专项记录](../../docs/audits/pat-service-wrapper-2.5-13/README.md)。

## 安装

用户当前为 **Rootless**，使用 [2.5-13 Rootless 安装包](com.wechat.improve_2.5-13_iphoneos-arm64.deb)。安装后重启微信，使新 Hook 生效；现有账号和自动功能配置继续使用。保持用户延迟为 0，在同一个群分别测试后台和锁屏，确认无需回前台即可回拍／回复。

另提供 [Rootful 包](com.wechat.improve_2.5-13_iphoneos-arm.deb)、[Rootful 重签用 dylib](WeChatImprove.dylib)、[调试符号](symbols.zip) 及 [SHA-256 清单](SHA256SUMS)。旧包均保留；如需回退至此前可后台回复的版本，使用 [2.5-11 Rootless 包](../2.5-11-pat-latency/com.wechat.improve_2.5-11_iphoneos-arm64.deb)。

## 针对本次回退的验证

新增跨模块测试使用**真实生产 Manager、同步协调器、服务 Environment、ABI 调用、拍动解析和磁盘去重**，不替换 Manager 的同步资格方法。原生录制服务由真正的 NSProxy 包装；Notify 必须在包装层安装的账号 context 下运行，否则测试失败。

| --- | --- | --- |
| 原生 setter 调用 | 1 | 1 |
| 同步请求 | 0 | 1 |
| 经代理发起同步 | 0 | 1 |

基线使用归档的旧 Core、旧 Manager 和旧生产 Environment。修复版还验证了两个独立磁盘 claim 与重复 SID 不再发送。这里的同步响应和最终发送是录制夹具，没有连接微信服务器。

最终跨模块测试 **528 项通过**，覆盖群聊／私聊、当前代理与同目标换代理、错误目标、未登记和错类登记代理、生命周期、账号 ABA epoch、配置或账号 getter 重入、前台边界、异常后的 context 恢复，以及“服务暂缺 → 保留兼容 timer → 服务恢复 → 立即消费已有 need、停止 timer”。Manager／Core／Environment 的 arm64、arm64e 均通过 `-Wall -Wextra -Werror` 编译。

另有事件协调器专项、Manager 前台／后台／dispatch-only、拍动后台集成、消息动作执行、AI 原生适配与完整同步观察、三组拍动入站／边界、共享预算和 AI 后台调度回归通过。本轮合计运行 **12 个相关验证脚本**；其中新增集成测试使用最终源码 SHA，覆盖最终修正的能力恢复分支。精确基线失败与修复通过日志保存于本机 `WeChatImprove-local-archive/audits/2.5-13/test-results/`；部分先行回归结果保留在会话工具输出中。

## 构建与包核验

将 **446 个生产输入**冻结至独立临时目录，使用现有 Theos、iPhoneOS 27.2 SDK、`DEBUG=0`、`FINALPACKAGE=1` 完成 Rootless／Rootful 构建，未执行 `make clean`。

包核验通过：版本 **2.5-13**，两种方案均包含 **arm64／arm64e**，最低 **iOS 15.0**；Debian 架构、安装目录、Rootless RPATH 和注入 plist 正确；四个 dSYM UUID 匹配各包切片，符号 ZIP CRC 和产物 SHA-256 校验通过。最终 checkout 与冻结构建输入 SHA 一致，此前 **72 个历史包目录文件**的内容、大小及修改时间保持。

本版已经在主机上复现并修复确定性代理阻断，但尚未在用户手机上完成实际送达验收。微信执行机会、原生通知交付与网络仍会影响实际时效；本轮没有修改保活策略、账号、配置、数据库或注入环境，也没有操作手机安装。
