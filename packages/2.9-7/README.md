# WeChatImprove 2.9-7 完整版

2.9-7 完整版沿用 beta06 的功能实现，汇总本轮聊天分组跟手转场、连续快滑、返回首滑准备和指示器同步调整。

## 完整功能

全量编译当前项目全部 297 个源码单元（240 个 Controllers 与 57 个 Hooks）。包含聊天分组、界面定制、气泡与列表样式、悬浮底栏、朋友圈布局、消息增强、输入框操作、自动回复、人工智能、定时任务、红包与收款、密友保护、账号辅助、配置备份与恢复等现有模块。具体功能继续由既有设置控制。

聊天分组的“页面转场动画”独立开关默认关闭。开启后，原页面与真实相邻列表跟随手指横向移动，取消时回弹，确认后从当前进度完成切换；指示器与页面进度同步，并从拖动位置完成收尾。保留快速连续横滑接续、返回聊天页首次来源准备、滚动位置恢复及真实布局验证，预览和取消不保存选择，确认时保存一次。系统“减弱动态效果”和原有账号、隐私、搜索、原生菜单与竖向滚动保护继续生效。

本次正式发布更新包版本、插件内版本及发布说明为 2.9-7，功能代码与 beta06 保持一致。
