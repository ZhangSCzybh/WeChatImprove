# WeChatImprove 3.0-3 完整版

正式整合 3.0-3 三个 Beta 版本的设置预览、分类整理与底栏功能键独立配色，包含全部既有模块。

## 本版内容

- 聊天分组、朋友圈布局、列表圆角和文本占位新增紧凑设置预览，顶栏信息在页面最下方展示预览。聊天分组与列表圆角设置按用途分类，保留原有功能和生效方式。
- 文本占位预览按聊天输入栏参考校准尺寸、占位位置和线条图标，朋友圈使用简洁的双列错落卡片示意；两者支持浅深色外观，预览使用示例内容。
- 分离和居中功能键分别提供背景颜色与图标颜色，两项默认跟随原生并各自支持恢复默认。支持透明度、实时预览、连续改色，以及配置备份、恢复和重置。
- 沿用底栏宽度比例输入、分离功能键大小 44–80 pt、居中按钮比例及独立间距。快速风格高度为 54／60／62 pt，保留已有自定义尺寸。
- 本次发布仅更新版本号与说明；功能实现与已交付的 3.0-3-beta03 一致。

## 下载与安装

| 文件 | 说明 |
| --- | --- |
| [com.wechat.improve_3.0-3_iphoneos-arm64.deb](com.wechat.improve_3.0-3_iphoneos-arm64.deb) | Rootless 完整包，安装至 `/var/jb/Library/MobileSubstrate/DynamicLibraries/` |
| [com.wechat.improve_3.0-3_iphoneos-arm.deb](com.wechat.improve_3.0-3_iphoneos-arm.deb) | Rootful 完整包，安装至 `/Library/MobileSubstrate/DynamicLibraries/` |
| [WeChatImprove.dylib](WeChatImprove.dylib) | 重签用动态库，与本版 Rootful 包内动态库完全一致 |
| [symbols.zip](symbols.zip) | 两套方案、两个架构共四份 dSYM |
| [SHA256SUMS](SHA256SUMS) | 本目录正式产物与说明的 SHA-256 校验值 |

两套安装包与动态库均包含 arm64／arm64e，最低编译目标 iOS 15.0。按设备现有注入环境选择对应产物。

**从 Beta 安装：** 按指定版本号 `3.0-3` 发布。Debian 版本规则将 `3.0-3` 排在旧格式的 `3.0-3-beta01`／`beta02`／`beta03` 之前；如果包管理器提示版本较低，请选择允许降级或重新安装，保留现有配置。此排序不代表本包缺少 Beta 中的功能。

## 核验

11 个核心脚本全部退出 0，覆盖聊天分组设置分区、列表圆角、顶栏更新与图片、朋友圈偏好、文本样式与滑动、底栏几何／结构／触摸／配色，以及备份注册、备份引擎和设置单元格布局。发布说明实现通过 arm64／arm64e 严格语法检查。

Rootless、Rootful 均完整编译 304 个源单元、双架构共 608 步，0 错误；每套各有 8 条既有警告，与此前构建一致，本次修改没有新增警告。已解包核验包 ID、版本、安装路径、注入 plist、架构、最低系统版本、staging 哈希、四份 dSYM UUID、预览与配色实现、重签库一致性和符号 ZIP CRC。

编译后的 42699 个冻结输入一致，任务开始时已有的 1236 个缓存与安装包文件保持原哈希。完整日志及结果见[审计说明](../../audits/3.0-3/README.md)。本轮没有安装原设备，画面和触摸仍需设备验收。
