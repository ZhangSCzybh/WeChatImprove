# 2.9-0 底栏松手直达与聊天分组按压

源码目录：`/Users/zhangshichao/Documents/Workspace/WeChatImprove`。本版在现有完整工作区上调整底栏点击与滑动的交互和动画，版本声明、插件内显示版本及本页统一为 `2.9-0`。交互依据来自附件 WeChatNeo 增强底栏的静态分析；实际手感、逐帧动画、触摸命中与不同微信版本的兼容性均为 **真机未验证**。

## 交互变化

- 点击特效现为“关闭 / 下划线 / 胶囊”；旧“轻弹”的设置值映射为 Neo 下划线。下划线名义宽度28pt、高度3pt，胶囊按 Neo 的槽位内缩、外扩、取整公式生成。自定义指示器颜色同时适用于两种效果。
- 手指按下即显示按压反馈，按下和拖动阶段只预览指示器，不提交页面切换。
- 拖动使用底栏内的绝对触点坐标，指示器与手指同向移动；从 A 经过 B 拖到 C 时，中间保持 A 页面，松手后直接切换到 C，只提交一次原生选择。
- 原生图标、文字、角标与用户选择入口继续保留。透明触摸层负责完整事件序列，避免起始按钮的原生抬手事件覆盖跨槽结果；原生禁用、隐藏和交互状态会守门。首页双击以0.36秒识别并转发原生未读入口。
- 在有效项目上松手后，指示器弹性归位到最终选中项目。拖回原项目、取消手势或在无效位置松手时，不切换页面。
- 本版按触点所在项目处理拖选，不再沿用相邻单步的位移百分比与抬手距离/速度提交模型。

## 底栏动画配置

| 阶段 | 配置 |
| --- | --- |
| 按压响应 | 0.12秒，EaseOut |
| 拖动 | 按当前触点直接更新指示器 |
| 松手/取消归位 | 0.46秒弹簧过渡，阻尼比0.62，初始速度参数0.82 |

以上为实现配置值，不是实测帧耗时。初始速度参数为固定动画参数，不能据此声称按真实抬手速度进行物理续接。编译和核心回归只能验证源码、链接及测试覆盖的行为，不能替代真机手感验证。

## 聊天分组胶囊按压

- 在“聊天分组 → 分组切换动画”选择“胶囊包裹”。手指按下即预览目标胶囊，使用0.12秒 EaseOut；背景采用与底栏中心按压相同的宽度1.08、高度1.04上限，并受当前分组按钮边界限制。
- 按压只改变背景和标题颜色过渡，标题、角标和按钮布局不缩放。按下不切换分组、不触发提交回调或切换触感；松手后沿用原有一次分组选择。
- 拖出或取消后恢复实际选中分组；滚动分组条或分组横滑接管时撤销按压，后续按钮抬手不会覆盖手势结果。
- 胶囊样式下关闭滚动容器的触摸延迟，并允许横向滚动取消按钮触摸；下划线保留原延迟设置。原有0.28秒胶囊选中/横滑收尾和0.20秒下划线过渡保留。
- 减弱动态效果时直接更新视觉状态。实际触摸延迟与动画观感真机未验证。
