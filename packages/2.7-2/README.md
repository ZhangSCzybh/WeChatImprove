# WeChatImprove 2.7-2

发布日期：2026-11-20。本版为 `2.7-2` 正式版，整合设置首页顶部账号区、随机文案与状态卡片的调整。最低编译目标为 iOS 15.0，提供 Rootless 与 Rootful 安装包。

## 更新内容

- **账号信息**：头像右侧上下排列昵称与微信号。微信号以普通文字显示，保留“微信号：”前缀；未取得微信号时显示原有提示。
- **SVIP 标识**：昵称后紧接白字 SVIP 胶囊，背景从五种预设颜色中随机选择；普通刷新和布局调整时保持选定颜色。长昵称自动省略并为 SVIP 预留空间。
- **顶部布局**：按账号信息、随机文案、三张状态卡片的顺序展示。卡片依次显示已开启功能数、插件版本和实际微信版本，并随文案高度调整位置，适配小屏与大字号。
- **随机文案**：每次进入设置首页请求新文案，诗词与随机一言两个来源按进入次数轮换，仅展示正文并去除末尾标题、作者或署名。上游随机内容可能重复。
- **失败回退**：首个来源失败或文案重复时尝试另一来源一次，请求不阻塞页面。两个来源均失败时使用缓存，无缓存时显示内置文案。

包元数据、插件内版本和当前更新说明统一为 `2.7-2`。历史版本说明与安装包保持原样。

## 验证范围

本轮聚焦版本同步、当前更新说明和顶部布局：核对包版本、插件内版本、当前说明键及安装链接，执行实际更新说明方法与顶部视图回归。当前说明仅介绍本版公开界面调整，历史说明未改写。

使用当前项目源码、独立临时构建目录编译，不清理原 `.theos` 或历史发布目录。测试使用临时文件与内存界面替身，不操作真实账号、聊天数据库或设置。具体结果见本目录核心校验和构建核验记录。

本轮未安装或重启原设备微信；最终视觉、网络与原生触摸交互仍需在原设备、原注入环境验收。

## 编译与产物核验结果

Rootless、Rootful 均从当前完整源码构建，每种方案全量编译 548 个编译单元，零错误；各有 8 条既有警告，诊断内容没有新增变化。两包版本均为 `2.7-2`，均包含 arm64、arm64e，最低 iOS 目标为 15.0，安装路径与对应注入方案一致。

各架构签名代码页哈希通过，四份 dSYM 的 UUID 与对应动态库匹配；独立 dylib 与 Rootful 包内动态库字节一致。构建前后 496 项生产输入摘要一致，2453 项历史发布文件及原构建产物摘要一致。本轮生产改动仅涉及版本常量、包版本及新增的当前版本说明，既有功能实现与历史说明保持原样。
